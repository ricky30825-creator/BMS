## 공통 반응형 UI 원칙

- 데스크톱은 사이드바와 다중 컬럼 레이아웃으로 요약 카드, 게이지, 차트, 이벤트 목록, 제어 상태를 한 화면에 최대한 유지한다.
- 태블릿은 접힘 메뉴와 2컬럼 카드/차트 배치를 기본으로 하며, 필터·기간 선택·제어 버튼은 터치 조작 가능한 크기를 유지한다.
- 모바일은 하단 내비게이션과 단일 컬럼 흐름을 사용한다. 긴급 경고, 현재 이상점수, 알림 확인, Kill-Switch 진입을 우선 노출한다.
- 표 중심 화면은 모바일에서 카드 목록/상세 화면으로 전환한다.
- WebSocket 연결이 끊기면 자동 재연결 상태를 표시하고, 실시간 데이터 갱신 중에도 카드 높이·차트 영역·상태 배지가 흔들리지 않도록 유지한다.
- 다크모드, 명도 대비, 키보드 탐색, 스크린리더 라벨을 고려한다.

**전이**
- 디바이스 관리 → 디바이스 등록/선택 → 배터리 자산관리
- 배터리 자산관리 → 새 배터리 등록 → `battery_id` 발급 → 배터리 자산관리
- 배터리 자산관리 → 저장된 배터리 선택 → QR/라벨 매칭 확인 → 측정 세션 준비
- 배터리 자산관리 → 배터리 상세/이력 → 과거 세션·점수 추세 확인

**배터리 선택 기준**
- 사용자는 저장된 배터리를 수동 선택한다. 보조배터리는 자동 고유 식별이 어렵기 때문에 `battery_id`와 사람이 확인하는 이름/라벨을 함께 사용한다.
- QR/라벨 확인은 잘못된 배터리 선택을 줄이기 위한 보조 확인 단계다.
- 배터리의 `target_mode`는 자산에 고정되어 있으므로 재연결 시 별도 모드 선택 화면을 요구하지 않는다.

- 조회 결과 → 데이터 내보내기(CSV/PDF)
- 장애 분석 필요 → 진단 패키지 내보내기

**분석 화면 표시**
- 추세 차트는 기간, 지표, 배터리, 세션 기준으로 필터링한다.
- 이벤트 이력은 목록 페이징, 검색, 상세 화면을 제공한다.
- 포렌식 타임라인은 위험 이벤트 전후 데이터, 점수, 제어, 알림 이력을 시간순으로 재구성한다.
- 진단 패키지는 로그, 설정, 최근 센서값, 모델 상태를 ZIP/PDF 형태로 묶는다.

## 핵심 사용자 여정

1. 시작 → 로그인 화면 → 일반/소셜 로그인 → 토큰 발급/갱신
2. 디바이스 관리 → 디바이스 등록/선택 → 배터리 자산관리
3. 저장된 배터리 선택 또는 새 배터리 등록 → QR/라벨 매칭 확인
4. 실험 레시피 선택 또는 직접 조건 입력 → 측정 전 안전 점검 → 측정 시작(세션 생성)
5. 실시간 대시보드 → 센서값·이상점수·상태등급·데이터 품질 확인
6. 경고/위험 발생 → 알림 확인(Ack) → XAI/이벤트 상세 확인 → SOP 확인
7. 필요 시 위험 제어 승인 모달 → 릴레이 차단 또는 복구
8. 측정 종료 → 배터리 상세/이력 → 추세 차트·포렌식 타임라인·데이터 내보내기
9. 설정 화면 → 임계치, 알림 수신, 테마, 캘리브레이션 이력 관리

> 모바일에서는 5~7번 흐름을 가장 짧게 접근할 수 있도록 하단 내비게이션과 위험 상태 카드에 알림 확인, SOP, Kill-Switch 진입을 우선 배치한다.

## HTML 프로토타입 확인 흐름

- 랜딩 화면은 제품, 실시간 관제, AI 이상탐지, 문의 메뉴와 로그인, 무료로 시작, 관제 시작하기, 데모 영상 버튼을 제공한다. 메뉴 앵커와 데모 영상의 실제 목적지는 HTML만으로 명확하지 않아 기능정의서 비고에 `정의 필요`로 표시한다.
- 로그인 모달은 일반 로그인, Google 로그인, 회원가입, 계정 찾기, 관리자 계정 진입을 제공한다. 계정 찾기 화면은 비밀번호 재설정과 이메일 찾기 탭으로 전환된다.
- 앱 셸은 사이드바 접기/펼치기, 한/영 언어 전환, 알림 패널, 로그아웃, 일반 사용자 메뉴 이동을 제공한다.
- 배터리 관리 화면은 저장된 배터리 목록, 모드 필터, 새 배터리 등록, 배터리 정보 수정, 배터리 연결 확인, 배터리 상세/이력 이동을 제공한다.
- 이벤트 이력 화면은 검색, 상태 필터, 정렬 메뉴, 페이지 이동, 이벤트 상세, CSV/PDF 내보내기 모달을 제공한다.
- 설정 화면은 임계치, 알림 수신, 계정, 테마 탭으로 나뉘며 알림 채널 토글, 비밀번호 재설정, 테마 선택, 센서 캘리브레이션 이력 확인이 포함된다.
