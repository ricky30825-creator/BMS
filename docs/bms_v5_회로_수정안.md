# BMS v5 회로 수정 설계안

> 원본 `bms_v5.net` 검증 결과 발견된 치명적 단락(배터리 +/− 단락, 3V3↔5V 단락)과
> 빠진 부품을 바로잡은 **재배선 설계서**입니다. KiCad 도면에서 이대로 다시 연결하세요.
>
> 모듈(TP4056·bq27441·MLX90614·릴레이·ZY12PDN)은 보드별 핀 순서가 달라 **신호 이름**으로 표기했습니다.
> 라즈베리파이·DS18B20·배터리(BT1)만 실제 핀번호입니다. 모듈은 보드 실크 이름에 맞춰 매핑하세요.

---

## 1. 핵심 수정 원칙

1. **전원 레일 3개 완전 분리**: `+5V`, `+3V3`, `GND`. (원본은 3V3과 5V가 한 넷, GND에 배터리·전원이 섞여 있었음)
2. **배터리 +/− 절대 같은 넷 금지.** BT1+ 는 측정 경로로, BT1− 만 GND.
3. **I2C 디바이스는 전부 3.3V로 구동** → SDA/SCL 로직이 3.3V로 유지되어 라즈베리파이 보호.
4. **빠진 부품 추가**: I2C 풀업 2개, 1-Wire 풀업 1개, (민짜 칩 사용 시) INA226 디커플링/션트.
5. **INA226 은 션트 내장 브레이크아웃(예: CJMCU-226) 권장** → 션트·캡 외부 부품 불필요, 심볼 핀 모호성 제거.

---

## 2. 전원 구조

```
RPi 5V  (pin2, pin4) ─────┬─ 릴레이모듈 VCC(코일)
                          └─ TP4056  IN+ (충전 입력)

RPi 3V3 (pin1)  ──────────┬─ INA226    VCC
                          ├─ bq27441   VDD
                          ├─ MLX90614  VCC   (※ 3V 버전 사용)
                          ├─ DS18B20   VDD (pin3)
                          ├─ R1,R2 (I2C 풀업)  공통 단자
                          └─ R3 (1-Wire 풀업)  단자

GND (RPi pin 6,9,14,20,25,30,34,39) ─ 모든 모듈 GND, BT1−, 부하 리턴
```

> ⚠️ MLX90614가 **5V 버전**이면 3.3V I2C에 직접 못 붙입니다(레벨시프터 필요). 가능하면 3V 버전(MLX90614xxx-DCI 등)을 쓰세요.
> ⚠️ 릴레이모듈은 **opto 절연·active-low** 모듈 권장. 코일 VCC=5V라도 IN 입력은 3.3V GPIO로 트리거되는 모듈을 고르세요(또는 VCC-JDVCC 점퍼 분리 후 로직측 3.3V 공급).

---

## 3. I2C 버스 (3.3V 로직)

| 신호 | 라즈베리파이 | 연결 대상 |
|---|---|---|
| SDA | pin3 (GPIO2) | INA226 SDA, bq27441 SDA, MLX90614 SDA, **R1(4.7kΩ)→3V3** |
| SCL | pin5 (GPIO3) | INA226 SCL, bq27441 SCL, MLX90614 SCL, **R2(4.7kΩ)→3V3** |

**I2C 주소 (충돌 없음 ✅)**: INA226 `0x40` (A0,A1→GND) / bq27441 `0x55` / MLX90614 `0x5A`

---

## 4. 온도센서 DS18B20 (1-Wire)

| DS18B20 핀 | 연결 |
|---|---|
| 1 (GND) | GND |
| 2 (DQ) | RPi pin24 (GPIO8) + **R3(4.7kΩ)→3V3** |
| 3 (VDD) | +3V3 |

> 원본대로 GPIO8 유지. 라즈베리파이 설정에 `dtoverlay=w1-gpio,gpiopin=8` 추가 필요.
> **DQ 풀업 4.7kΩ 은 필수** (원본에 없었음).

---

## 5. 릴레이 — 제어선 + 스위칭 접점

### 5-1. 제어 헤더 (J3, 3채널 릴레이 모듈)
| 릴레이모듈 | 연결 |
|---|---|
| VCC | +5V |
| GND | GND |
| IN1 | RPi pin7  (GPIO4) |
| IN2 | RPi pin29 (GPIO5) |
| IN3 | RPi pin31 (GPIO6) |

### 5-2. 스위칭 접점 (J4=CH1, J6=CH2, J5=CH3) — **모드 선택 인터락**
> 원본은 접점이 전부 GND에 묶여 무의미했음. 아래처럼 **각 모드의 소스(+)를 공통 측정버스 `MEAS+` 로 절체**합니다.
> 인터락(상호배제)은 소프트웨어에서 한 번에 한 채널만 ON 으로 보장.

| 채널 | 모드 | COM (소스 +) | NO (→ MEAS+) | NC |
|---|---|---|---|---|
| CH1 (J4) | 모드1 내장배터리 | TP4056 OUT+ / 내장배터리+ | MEAS+ | 미사용 |
| CH2 (J6) | 모드2 외부셀 | BT1 + | MEAS+ | 미사용 |
| CH3 (J5) | 모드3 보조배터리 | ZY12PDN OUT+ (PD 출력) | MEAS+ | 미사용 |

## 6. 측정 경로 (배터리 ↔ 전류센서 ↔ 부하) — **가장 크게 바뀐 부분**

```
[선택된 소스 +] ─(릴레이 CHx NO)─ MEAS+ ─ INA226 VIN+ )
                                                        ) 션트(모듈 내장)
[부하 J2]  ── INA226 VIN− ───────────────────────────── )
   │
   └─ J2 다른 핀 ── GND

모든 소스(−) ─ GND
```

| 노드 | 연결 |
|---|---|
| INA226 VIN+ | MEAS+ (릴레이로 선택된 소스 +) |
| INA226 VIN− | 부하 J2 한쪽 핀 |
| J2 반대쪽 핀 | GND |
| INA226 VCC | +3V3 |
| INA226 GND | GND |
| INA226 ALERT | (선택) RPi 여유 GPIO, 또는 미연결. **GND 직결 금지** |

> 이렇게 해야 전류가 `소스+ → 션트 → 부하 → GND` 로 흘러 INA226이 전류·전력을 측정합니다.
> 원본은 VIN+/VIN−가 모두 GND라 측정 불가 + 배터리 단락이었습니다.

## 9. ZY12PDN PD 트리거 (모드3 보조배터리)

| ZY12PDN | 연결 |
|---|---|
| OUT+ (V+) | 릴레이 CH3 COM |
| OUT− (V−) | GND |

> 원본은 출력(pin2)이 어디에도 안 붙어 모드3가 동작하지 않았습니다.

## 12. 내가 임의로 결정한 부분 (확인해 주세요)

- **릴레이 모드-절체 토폴로지(6장·5-2)**: 각 모드 소스(+)를 공통 측정버스로 절체하는 구조로 가정했습니다.
  실제 의도(예: 릴레이가 배터리 차단 킬스위치인지, 모드 입력 절체인지)가 다르면 이 부분을 바꿔야 합니다.
- **부하(J2 "load tester")** 가 INA226 VIN−와 GND 사이에 들어가는 부하라고 가정했습니다.
- **MLX90614 / 릴레이모듈 전압**: 3V/5V 버전, opto 절연 여부에 따라 레벨시프터/점퍼가 필요할 수 있습니다.
