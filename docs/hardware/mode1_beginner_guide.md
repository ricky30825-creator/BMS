# 모드 1 회로 조립 — 초보자 가이드

전자회로를 한 번도 안 만져본 사람이 이 문서만 보고 모드 1(외부 셀) 계측 회로를 조립할 수 있게 쓴 문서다.

- 회로도: `hardware/mode1/cellguard_mode1.kicad_pro` (KiCad로 열기) 또는 `hardware/mode1/cellguard_mode1.svg` (브라우저로 열기)
- 백엔드 개발자용 문서: `docs/hardware/mode1_backend_spec.md`

## 0. 시작하기 전에 — 리튬이온 안전 수칙

리튬이온 셀은 잘못 다루면 **불이 난다.** 물로 못 끄고, 한 번 시작되면 못 멈춘다. 이 프로젝트는 애초에 그 현상을 관찰하려는 것이므로 더더욱 조심해야 한다.

**절대 하지 말 것**

| 하지 말 것 | 왜 |
|---|---|
| 셀의 + 와 − 를 직접 잇기 (단락) | 수십 A가 흘러 몇 초 만에 발화한다. 공구·금속 시계·반지 조심 |
| 셀에 직접 인두질 | 열이 셀 내부로 들어가 분리막이 녹는다. **반드시 18650 홀더**를 쓴다 |
| 4.2V 넘게 충전 | 과충전이 열폭주의 가장 흔한 원인 |
| 3.0V 아래로 방전 | 셀이 영구 손상되고, 그 상태로 충전하면 내부 단락이 생긴다 |
| 부풀거나 찌그러진 셀 사용 | 이미 내부가 손상된 셀이다. 폐기한다 |
| 극성 반대로 연결 | Babysitter와 INA226이 즉시 파손된다 |
| 자리를 비우고 충·방전 방치 | 반드시 사람이 지켜본다 |

**준비물**: 불연성 트레이(금속 상자·화분 받침), 모래 또는 D급 소화기, 환기, 가연물 없는 작업대.

## 1. 이 회로가 하는 일

셀 하나를 **충전**했다가 **방전**시키면서, 그동안의 전압·전류·온도·SOC·압력을 라즈베리파이가 계속 기록한다. 이상이 보이면 릴레이로 전기를 끊는다.

전기가 흐르는 길은 딱 두 가지다.

### 충전 중

```
  ZY12PDN            릴레이 CH1        Battery Babysitter
  (USB-C 5V)  ────────  닫힘  ────────▶  VIN
                                          │  BQ24075 충전기가
                                          │  5V를 4.2V로 낮춰 셀에 넣음
                                        BAT+
                                          │
                                    릴레이 CH3 (닫힘)
                                          │
                                      INA226 션트   ◀── 여기서 전류를 잰다
                                          │
                                         F1 퓨즈
                                          │
                                        셀 +

  셀 − ────────────────────────────▶ Babysitter BAT−
                                     (BQ27441이 여기서 SOC를 잰다)

  릴레이 CH2 = 열림  (방전 경로 차단)
```

### 방전 중

```
                                        셀 +
                                          │
                                         F1 퓨즈
                                          │
                                      INA226 션트   ◀── 전류가 반대로 흐름
                                          │
                                    릴레이 CH3 (닫힘)
                                          │
                                        BAT+
                                          │  Babysitter 내부를 지나
                                        SYS+
                                          │
                                    릴레이 CH2 (닫힘)
                                          │
                              ATORCH BW150 전자부하  ◀── 전기를 열로 태워 없앰

  릴레이 CH1 = 열림  (충전 경로 차단)
```

### 차단됨 (Kill-Switch)

```
  릴레이 CH1 = 열림    충전 못 함
  릴레이 CH2 = 열림    방전 못 함
  릴레이 CH3 = 열림    셀이 회로에서 완전히 떨어져 나감

  ▶ 그래도 INA226은 계속 셀 전압을 읽는다.
    INA226은 셀이 아니라 라즈베리파이의 3.3V로 동작하기 때문이다.
  ▶ 대신 BQ27441(SOC)은 꺼진다. 셀에서 전원을 받기 때문이다.
```

**릴레이는 전기로 움직이는 스위치다.** 그리고 이 회로의 모든 배터리 경로는 릴레이의 **NO(Normally Open, 평소 열림)** 접점을 지난다. 즉 **전기가 안 들어오면 스위치가 저절로 열린다.** 정전이 되든, 라즈베리파이가 꺼지든, 프로그램이 죽든 배터리는 자동으로 분리된다. 이걸 fail-safe(고장나도 안전한 쪽으로)라고 한다.

## 2. 부품 하나씩

부품 봉투에 이름이 안 적혀 있을 수 있다. **보드 위에 인쇄된 글자(실크스크린)**로 구분한다.

| 회로도 기호 | 실물 찾는 법 | 하는 일 |
|---|---|---|
| **BT1** | 18650 원통형 셀 / 납작한 리튬폴리머 파우치 | 측정 대상 |
| **F1** | 아직 없음 — 사야 함 | 과전류가 흐르면 스스로 끊는 퓨즈. 안전장치 |
| **U1 INA226** | 파란/보라 작은 보드, 칩 옆에 굵은 저항 하나(`R100`/`R010`/`R002` 등) | 전압·전류·전력 측정 |
| **U2 Babysitter** | 빨간 SparkFun 보드, `PRT-13777`, JST 커넥터 + 마이크로 USB | 충전기 + SOC 측정기 |
| **U3·U9 MLX90614 ×2** | 파란 DFRobot Gravity 보드, 은색 원통형 센서, 4색 케이블 | 안 닿고 표면온도 측정. **2개를 다른 지점에 겨눈다** — §4-5. 하나는 주소를 바꿔야 함 — §3-⑤ |
| **U4 ADS1115** | 자주색 작은 보드, `ADS1115` 인쇄 | 아날로그 값을 숫자로 바꿔줌 |
| **U5·U7·U8 DS18B20 ×3** | 스테인리스 원통 + 3색(빨강/노랑/검정) 방수 케이블 | 셀에 붙여서 온도 측정. **3개를 같은 선에 병렬로** — §4-3b |
| **U6 OLED** | 0.96인치 검은 화면, 핀 7개 (`GND VCC D0 D1 RES DC CS`) | 현장에서 상태 표시 |
| **K1 릴레이** | 파란 정육면체 4개가 붙은 보드, 초록 나사 단자 | 전기를 붙였다 뗐다 하는 스위치 |
| **J1** | 라즈베리파이 5의 40핀 헤더 | 두뇌 |
| **J2 ZY12PDN** | 아주 작은 보드, USB-C 소켓 + 버튼 + LED | USB-C 충전기에서 5V를 뽑아옴 |
| **J3 BW150** | 커다란 검은 상자, 화면 + 팬 | 전기를 열로 태워 없애는 "가짜 부하" |
| **RV1 FSR 406** | 얇고 납작한 필름 센서, 원형 감지부 | 셀이 부풀면 눌리는 힘을 측정 |
| **R1~R6** | 색띠 있는 작은 저항 — 아직 없음, 사야 함 | 아래 설명 |

> **왜 온도 센서를 5개나 쓰는가?**
>
> 열폭주는 셀 전체가 고르게 뜨거워지는 게 아니라 **한 곳에서 시작한다.** 센서가 1개면 그 지점을 비껴갔을 때 아무것도 못 잡는다.
>
> 특히 MLX90614(적외선)는 **시야각 안에 들어온 것들의 평균 온도**를 낸다. 사진처럼 한 점을 찍는 게 아니라 넓은 원을 통째로 평균 내는 것이라, 한 귀퉁이만 뜨거우면 그 신호가 희석돼 사라진다. 그래서 **2개를 서로 다른 곳에 겨눠 놓고 둘 중 더 뜨거운 쪽을 쓴다.**
>
> DS18B20(접촉식)도 같은 이유로 3점을 재고 가장 높은 값을 쓴다. 지점끼리 온도가 벌어지는 것 자체가 "어딘가 국부적으로 타고 있다"는 강한 증거다.

> **왜 저항이 필요한가?**
> - **R1 (10kΩ)**: FSR은 "저항이 변하는 부품"이지 "전압을 내는 부품"이 아니다. 저항 하나를 짝지어야 전압으로 바뀌어 읽힌다(분압).
> - **R2 (4.7kΩ)**: 1-Wire 통신은 신호선을 평소에 3.3V로 끌어올려 둬야 동작한다(풀업). 이게 없으면 DS18B20이 아예 안 보인다.
> - **R3~R6 (10kΩ)**: 라즈베리파이가 켜지는 아주 짧은 순간, GPIO 핀 상태가 정해지지 않는다. 그 틈에 릴레이가 붙어버리면 위험하므로 저항으로 3.3V에 묶어 "떨어짐" 상태를 강제한다.

## 3. 조립 전 반드시 확인할 5가지

**여기서 틀리면 부품이 탄다. 배선하기 전에 하나씩 확인한다.**

### ① ZY12PDN을 5V로 설정했는가

ZY12PDN은 USB-C 충전기에서 5V·9V·12V·15V·20V 중 하나를 골라 뽑아오는 부품이다. 버튼으로 전압을 바꾼다.

- **반드시 5V.** Babysitter의 충전 칩(BQ24075)은 5V용이라 9V 이상이 들어가면 즉시 탄다.
- USB-C를 꽂고 **멀티미터로 VOUT+ / VOUT− 사이 전압이 5V인지 직접 재고 나서** 회로에 연결한다.
- ZY12PDN이 없거나 불안하면 **평범한 5V USB 충전기**를 써도 된다. 이 회로에서 필요한 건 5V뿐이다.

### ② 릴레이 모듈의 `VCC`–`JD-VCC` 점퍼를 뽑았는가

릴레이 보드에는 검은 점퍼 캡이 두 핀에 꽂혀 있다. **이걸 뽑는다.**

- 뽑으면 `VCC`(신호 쪽)와 `JD-VCC`(코일 쪽)를 따로 먹일 수 있게 된다.
- **`VCC` → 라즈베리파이 3.3V**, **`JD-VCC` → 5V**, `GND` → 공통.
- 점퍼를 꽂아 두면 `VCC`가 5V가 되는데, 라즈베리파이 신호는 3.3V다. 5 − 3.3 = 1.7V라 신호가 "꺼짐"으로 확실히 인식되지 않아 릴레이가 제멋대로 움직인다.

### ③ INA226 보드의 션트 저항값을 읽었는가

INA226 칩 옆의 **굵고 납작한 저항**에 인쇄된 글자를 읽는다.

| 인쇄 | 값 | 잴 수 있는 최대 전류 | 판정 |
|---|---|---|---|
| `R002` 또는 `2m` | 0.002Ω | 약 3.3A | 쓸 수 있음 |
| `R010` 또는 `10m` | 0.01Ω | 약 3.3A | **가장 적합** (같은 상한에서 잡음이 적다) |
| `R100` 또는 `0.1` | 0.1Ω | 약 0.8A | 부적합 — 2A 흘리면 0.2V가 저항에서 날아가고 0.4W가 열로 나온다 |

> **왜 R002와 R010의 상한이 같은가?** 상한을 정하는 게 저항이 아니라 칩 내부의 16비트 전류 레지스터이기 때문이다. 소프트웨어 설정에 따라 달라지므로 자세한 건 백엔드 문서 §3-3에 있다. 조립자는 **실크스크린 글자만 정확히 읽어 알려주면 된다.**

**읽은 값을 백엔드 개발자에게 알려준다.** 이 값으로 소프트웨어의 Calibration 값을 계산한다(`docs/hardware/mode1_backend_spec.md` §3).

### ④ 셀의 −(음극)를 시스템 GND에 직접 연결하지 마라

**이게 가장 헷갈리는 부분이다.**

셀의 −는 **오직 Babysitter의 `BAT−`(JST 커넥터의 검은선) 하나에만** 간다. 라즈베리파이 GND나 다른 부품의 GND에 같이 묶으면 안 된다.

> **왜?** Babysitter 보드 안에서 `BAT−`와 보드 `GND` 사이에 아주 작은 저항(20mΩ)이 들어 있다. BQ27441은 이 저항 양끝의 미세한 전압차를 재서 전류를 계산하고, 그걸 누적해 SOC(%)를 만든다. 셀 −를 GND에 직결하면 이 저항이 **단락(우회)** 되어 BQ27441이 전류를 못 읽고 SOC가 엉터리가 된다.

회로도에서 이 선의 이름이 `CELL_N`이며, 붙어 있는 곳이 딱 두 군데(`BT1.−`, `U2.BAT−`)뿐인 이유가 이것이다.

### ⑤ MLX90614 두 개 중 하나의 주소를 바꿨는가

**두 센서 모두 공장 출고 시 주소가 `0x5A`로 같다.** 그대로 둘 다 연결하면 둘이 동시에 대답해서 통신이 깨진다. **하나를 `0x5B`로 바꿔야 한다.**

**⚠️ 반드시 한 개씩 따로 연결해서 작업한다.** 두 개를 물린 채로 주소를 쓰면 둘 다 바뀌어 버려 원점이다.

```bash
# 1. #2로 쓸 센서 하나만 연결한다 (#1은 뽑아 둔다)
sudo i2cdetect -y 1        # 5a 하나만 보여야 한다

# 2. 주소를 0x5B로 바꾼다
python3 - <<'EOF'
from smbus2 import SMBus
import time
with SMBus(1) as bus:
    print("현재:", hex(bus.read_word_data(0x5A, 0x2E)))
    bus.write_word_data(0x5A, 0x2E, 0x0000)   # 지우기
    time.sleep(0.05)
    bus.write_word_data(0x5A, 0x2E, 0x005B)   # 새 주소 (하위 바이트만)
    time.sleep(0.05)
    print("기록됨:", hex(bus.read_word_data(0x5A, 0x2E)))
EOF

# 3. 전원을 껐다 켠다  ← EEPROM은 재시작해야 적용된다
sudo i2cdetect -y 1        # 이제 5b 로 보여야 한다

# 4. #1을 다시 연결하고 둘 다 확인
sudo i2cdetect -y 1        # 5a 와 5b 가 같이 보인다
```

- `0x2E`는 EEPROM 주소 `0x0E`에 `0x20`을 더한 값이다. MLX90614는 EEPROM에 접근할 때 이렇게 커맨드를 만든다.
- **주소를 바꾼 센서에는 케이블에 라벨을 붙여 둔다.** 안 그러면 나중에 어느 게 `0x5B`인지 겉으로는 구분할 방법이 전혀 없다.
- 주소를 잘못 써서 센서를 못 찾게 됐다면, 주소 `0x00`으로 접근하면 MLX90614가 자기 주소와 무관하게 항상 대답한다. 이때도 버스에 센서가 하나뿐이어야 한다.

> **DS18B20은 이런 작업이 필요 없다.** 1-Wire는 센서마다 공장에서 구워진 고유 64비트 번호가 있어서, 세 개를 그냥 병렬로 물리기만 하면 알아서 구분된다.

## 4. 배선표

라즈베리파이의 **물리 핀 번호**로 적었다. 핀 번호는 헤더의 사각 패드(1번)를 기준으로 **위에서 아래로 지그재그**다. 왼쪽 줄이 홀수(1,3,5…), 오른쪽 줄이 짝수(2,4,6…)다.

### 4-1. 라즈베리파이 ↔ 부품

| 체크 | Pi 물리 핀 | Pi 기능 | 연결 대상 | 추천 색 |
|---|---|---|---|---|
| ☐ | **1** | 3.3V | INA226 `VCC`, **MLX90614 ×2** `VCC`(빨강), ADS1115 `VDD`, **DS18B20 ×3** `VDD`(빨강), OLED `VCC`, 릴레이 `VCC` | 빨강 |
| ☐ | **2** | 5V | 릴레이 `JD-VCC` | 주황 |
| ☐ | **3** | GPIO2 / SDA | INA226 `SDA`, Babysitter `SDA`, **MLX90614 ×2** `SDA`(파랑), ADS1115 `SDA` | 파랑 |
| ☐ | **5** | GPIO3 / SCL | INA226 `SCL`, Babysitter `SCL`, **MLX90614 ×2** `SCL`(초록), ADS1115 `SCL` | 초록 |
| ☐ | **7** | GPIO4 | **DS18B20 ×3의 `DQ`(노랑) 전부** + R2(4.7kΩ)의 한쪽 — §4-3b | 노랑 |
| ☐ | **17** | 3.3V | R1·R2·R3~R6·FSR406의 3.3V 쪽 | 빨강 |

| ☐ | **35** | GPIO19 | 릴레이 `IN4` (예비) + R6 | 갈색 |
| ☐ | **6, 9, 14, 20, 25, 30, 34, 39** | GND | 아래 GND 목록 전부 | 검정 |

> 3.3V 핀은 1번과 17번 둘뿐인데 연결할 곳이 많다. **작은 브레드보드나 분배 단자대를 하나 두고 거기서 나눠 쓴다.** 핀 하나에 여러 선을 억지로 꽂지 않는다.

### 4-2. GND에 모을 것 (전부 한 점에 모은다 — 스타 그라운드)

☐ INA226 `GND` ☐ MLX90614 #1 `GND`(검정) ☐ MLX90614 #2 `GND`(검정) ☐ ADS1115 `GND` ☐ ADS1115 `ADDR` ☐ DS18B20 #1·#2·#3 `GND`(검정) ☐ OLED `GND` ☐ 릴레이 `GND` ☐ Babysitter `GND` ☐ Babysitter `GND_IN` ☐ Babysitter `SYS−` ☐ ZY12PDN `VOUT−` ☐ BW150 부하 `−` ☐ R1의 반대쪽

> **`ADS1115 ADDR` → GND** 는 배선 실수가 아니다. ADDR 핀을 GND에 묶으면 I2C 주소가 `0x48`로 정해진다. 안 묶으면 주소가 떠서 안 잡힌다.

### 4-3. 전력 경로 (굵은 선 — 0.75SQ 실리콘 배선 사용)

| 체크 | 회로도 네트 | 어디서 | 어디로 |
|---|---|---|---|
| ☐ | `CELL_P` | 셀 **+** | F1 퓨즈 한쪽 |
| ☐ | `CELL_P_F` | F1 퓨즈 반대쪽 | INA226 `IN−` **그리고** INA226 `VBUS` |
| ☐ | `RLY_CH3_IN` | INA226 `IN+` | 릴레이 **CH3 COM** |
| ☐ | `RLY_CH3_OUT` | 릴레이 **CH3 NO** | Babysitter `BAT+` |
| ☐ | `CELL_N` | 셀 **−** | Babysitter `BAT−` **(여기만!)** |
| ☐ | `V5_PD` | ZY12PDN `VOUT+` | 릴레이 **CH1 COM** |
| ☐ | `RLY_CH1_OUT` | 릴레이 **CH1 NO** | Babysitter `VIN` |
| ☐ | `SYS_P` | Babysitter `SYS+` | 릴레이 **CH2 COM** |
| ☐ | `RLY_CH2_OUT` | 릴레이 **CH2 NO** | BW150 부하 **+** |

> 릴레이 나사 단자는 채널마다 3개다: 가운데가 `COM`, 양옆이 `NO`와 `NC`. **`NC`는 쓰지 않는다.** `NO`가 어느 쪽인지는 보드에 인쇄돼 있다.

### 4-3b. 온도 센서 다점 배선

**DS18B20 3개는 같은 3선에 그냥 병렬로 문다.** 주소 설정도, 별도 핀도 필요 없다.

```
Pi 핀 1 (3.3V) ──┬── #1 빨강 ──┬── #2 빨강 ──┬── #3 빨강
                 │             │             │
                [R2 4.7kΩ]     │             │
                 │             │             │
Pi 핀 7 (GPIO4)──┴── #1 노랑 ──┴── #2 노랑 ──┴── #3 노랑
                                                   
Pi GND ──────────── #1 검정 ──── #2 검정 ──── #3 검정

※ 4.7kΩ 풀업은 버스 전체에 하나만 있으면 된다. 센서마다 달지 않는다.
```

| 체크 | 연결 |
|---|---|
| ☐ | DS18B20 #1·#2·#3의 빨강을 모두 3.3V에 |
| ☐ | DS18B20 #1·#2·#3의 노랑을 모두 GPIO4(핀 7)에 |
| ☐ | DS18B20 #1·#2·#3의 검정을 모두 GND에 |
| ☐ | R2(4.7kΩ)는 3.3V와 GPIO4 사이에 **하나만** |

**MLX90614 2개도 같은 I2C 2선에 병렬로 문다.** 주소만 서로 달라야 한다(§3-⑤).

| 체크 | 연결 |
|---|---|
| ☐ | MLX90614 #1(0x5A)·#2(0x5B)의 파랑(SDA)을 모두 핀 3에 |
| ☐ | MLX90614 #1·#2의 초록(SCL)을 모두 핀 5에 |
| ☐ | MLX90614 #1·#2의 빨강(VCC)을 모두 3.3V에, 검정(GND)을 모두 GND에 |

### 4-4. 나머지

| 체크 | 연결 |
|---|---|
| ☐ | FSR406 한쪽 → 3.3V |
| ☐ | FSR406 반대쪽 → R1(10kΩ) 한쪽 → **동시에** ADS1115 `A0` |
| ☐ | R1 반대쪽 → GND |
| ☐ | R2(4.7kΩ) → 3.3V와 GPIO4(핀 7) 사이 |
| ☐ | R3(10kΩ) → 3.3V와 GPIO5(핀 29) 사이 |
| ☐ | R4(10kΩ) → 3.3V와 GPIO6(핀 31) 사이 |
| ☐ | R5(10kΩ) → 3.3V와 GPIO13(핀 33) 사이 |
| ☐ | R6(10kΩ) → 3.3V와 GPIO19(핀 35) 사이 |
| ☐ | ADS1115 `A1`·`A2`·`A3`, `ALRT` → 아무 데도 안 붙임 |

### 4-5. ⚠️ 센서를 셀에 붙이는 위치

배선만큼 중요하다. 잘못 두면 값이 조용히 틀린다.

```
        [IR #1 0x5A]              [IR #2 0x5B]
         셀 중앙 조준              단자쪽 조준
              ▼                        ▼
           ~2cm                      ~2cm
              ▼                        ▼
   ┌──────────────────────────────────────┐
   │  ●              ●              ●     │ ⊕   ← 양극 단자
   └──────────────────────────────────────┘
     DS18B20 #1     #2             #3
     (하단)        (중앙)        (단자쪽)

            18650   길이 65mm × 지름 18mm
```

**왜 단자쪽에 하나를 몰아 두는가**: 양극 단자 부근은 내부 저항이 가장 크고 접촉 저항까지 겹쳐 **가장 먼저 뜨거워지는 곳**이다. 셀 중앙만 재면 이 초기 신호를 놓친다.

#### MLX90614 ×2 (IR 온도) — 셀 표면에서 **2cm 이내**

이 센서는 **원뿔 모양 시야(35°) 안에 들어온 모든 것의 평균 온도**를 잰다. 사진처럼 한 점을 찍는 게 아니다. 멀리 두면 셀 주변의 상온 공기와 배경이 같이 섞여서 **실제 셀보다 낮게** 읽힌다.

| 센서~셀 거리 | 실제로 재는 원의 지름 | 18650(지름 1.8cm)에서 |
|---|---|---|
| 1cm | 0.63cm | 셀 안에 쏙 들어감 |
| **2cm** | **1.26cm** | 셀 안에 들어감 — **여기까지** |
| 3cm | 1.89cm | 셀 폭을 살짝 넘음 |
| 5cm | 3.15cm | 배경이 절반 넘게 섞임 |
| 10cm | 6.31cm | 거의 배경 온도를 재는 셈 |

- **#1은 셀 중앙, #2는 양극 단자 부근**을 겨눈다. 두 시야가 겹치지 않게 최소 2cm는 떨어뜨려 배치한다.
- 은색 원통형 센서 렌즈가 셀 옆면을 **정면으로** 보게 한다.
- 렌즈에 테이프나 먼지가 묻으면 안 된다. 유리가 아니라 적외선용 창이라 가려지면 값이 죽는다.
- 센서 **뒤나 옆에 뜨거운 것을 두지 마라.** 센서 몸통에 온도차가 생기면 값이 틀어진다.

#### DS18B20 ×3 (접촉 온도) — 하단 / 중앙 / 단자쪽

- 스테인리스 끝부분이 셀 표면에 **완전히 닿아야** 한다. 뜨는 부분이 있으면 공기 온도를 잰다.
- 서멀 패드를 사이에 끼우고 캡톤 테이프로 고정한다. **3개니까 서멀 패드도 3장 필요하다.**
- 셀 길이 65mm를 대략 3등분해 배치하되, **#3은 양극 단자에 최대한 가깝게** 붙인다.
- ⚠️ **어느 센서가 어디에 붙었는지 기록해야 한다.** 센서마다 고유 번호(`28-...`)가 있지만 그 번호만 봐서는 위치를 알 수 없다. 확인법:
  ```bash
  # 손가락으로 센서 하나만 잡고
  for f in /sys/bus/w1/devices/28-*/w1_slave; do echo "$f"; tail -1 "$f"; done
  # 값이 올라간 것이 그 센서다. 셋을 반복해 표를 만들고 설정 파일에 적는다.
  ```

#### FSR 406 (압력) — 셀 옆면과 고정된 판 사이에 끼움

- 셀이 부풀면 눌리도록, 셀과 케이스 벽 사이에 넣고 살짝 예압을 준다.
- 감지부(원형)가 셀에 눌리게 해야 한다. 배선 꼬리 부분이 눌리면 안 된다.

## 5. 조립 순서 — 3단계

**절대 순서를 바꾸지 마라.** 배터리는 맨 마지막이다.

### 1단계 — 배터리 없이, 전원도 없이 (신호선만)

1. 라즈베리파이의 **전원을 뽑는다.**
2. §4-1, §4-2, §4-4의 신호선·전원선·GND를 전부 연결한다.
3. §4-3의 **전력 경로는 아직 연결하지 않는다.**
4. 배선표 체크박스를 하나씩 다시 훑는다. **특히 SDA(핀 3)와 SCL(핀 5)이 안 바뀌었는지.**
5. 3.3V 선이 GND에 닿아 있지 않은지 멀티미터 저항 측정으로 확인한다(수백 Ω 이상이면 정상, 0Ω이면 단락).

### 2단계 — 배터리 없이 전원만

1. 라즈베리파이에 전원을 넣는다. 셀은 아직 꽂지 않는다.
2. I2C를 켠다: `sudo raspi-config` → `Interface Options` → `I2C` → `Yes`. SPI도 같은 방법으로 켠다.
3. 1-Wire를 켠다. `/boot/firmware/config.txt` 맨 아래에 추가:
   ```
   dtoverlay=w1-gpio,gpiopin=4
   gpio=5,6,13,19=op,dh
   ```
   두 번째 줄은 부팅하자마자 릴레이 신호 4개를 "떨어짐(1)"으로 고정하는 안전장치다.

   재부팅한 뒤 이 줄이 실제로 먹었는지 확인한다:
   ```bash
   pinctrl get 5,6,13,19      # 네 핀이 op dh 로 나와야 한다
   ```
   ⚠️ **라즈베리파이 5에서 이 줄이 안 먹을 수도 있다.** Pi 5는 GPIO를 다른 칩(RP1)이 담당하도록 바뀌어서 일부 설정이 예전과 다르게 동작한다. **안 먹어도 괜찮다** — R3~R6 저항이 전원이 들어오는 순간부터 같은 일을 하고, 그게 소프트웨어에 기대지 않는 유일한 안전장치다. 그래서 **저항 4개를 생략하면 안 된다.**
4. 재부팅한 뒤 확인:
   ```bash
   sudo i2cdetect -y 1
   ```
   **`48`, `5a`, `5b`가 보여야 한다.** (`40`은 INA226에 전력 배선이 아직 없어도 보일 수 있고, `55`는 셀을 꽂아야 보인다 — BQ27441은 셀에서 전원을 받기 때문이다.)

   `5b`가 안 보이면 §3-⑤의 주소 변경이 안 된 것이다. `5a`만 보이는데 값이 이상하게 튄다면 **두 센서가 모두 `0x5A`라 충돌하는 것**이니 하나를 뽑고 다시 §3-⑤를 한다.
5. 릴레이 4개가 전부 **"딸깍" 소리 없이 조용히** 있어야 한다. 소리가 나면서 붙어 있다면 §7-3을 본다.

### 3단계 — 셀 연결

1. **전원을 다시 뽑는다.**
2. §4-3의 전력 경로를 연결한다. **셀은 아직**.
3. 셀을 홀더에 끼우고, 홀더 선을 회로에 연결한다. **극성 두 번 확인.**
4. 전원을 넣고 다시 `sudo i2cdetect -y 1` — 이제 **`40 48 55 5a` 네 개가 다 보여야 한다.**
5. 온도 센서 확인:
   ```bash
   ls /sys/bus/w1/devices/
   ```
   **`28-` 으로 시작하는 디렉토리가 3개** 보여야 한다. 2개면 하나가 접촉 불량이거나 배선이 빠진 것이다.

   값도 확인한다:
   ```bash
   for f in /sys/bus/w1/devices/28-*/w1_slave; do tail -1 "$f"; done
   ```
   `t=` 뒤 숫자를 1000으로 나눈 게 섭씨다. `85000`이 나오면 4.7kΩ 풀업이 없거나 전원이 부족한 것이다.

6. **어느 DS18B20이 어디에 붙었는지 표를 만든다** (§4-5 참조). 이걸 안 하면 백엔드가 "단자쪽 온도"를 특정할 수 없다.

## 6. 처음 만져볼 때 — 릴레이 동작 확인

**셀을 빼고** 한다. 릴레이는 `0`이 "붙음", `1`이 "떨어짐"이다(active-LOW).

```bash
# 릴레이 IN3 (마스터, GPIO13) 을 붙였다 뗐다
pinctrl set 13 op dl    # 0 → "딸깍" 붙음
pinctrl set 13 op dh    # 1 → "딸깍" 떨어짐
```

네 채널(GPIO 5, 6, 13, 19)이 모두 소리가 나면 정상이다. 끝나면 **반드시 전부 `dh`(떨어짐)로 되돌린다.**

## 7. 자주 하는 실수 10가지

1. **SDA와 SCL을 바꿔 꽂음** → `i2cdetect`에 아무것도 안 나온다. 가장 흔하다. 핀 3 = SDA, 핀 5 = SCL.
2. **GND를 공통으로 안 묶음** → 값이 미친 듯이 튄다. 모든 부품의 GND는 반드시 한 점에 모인다.
3. **셀 −를 GND에 직결** → SOC가 0% 또는 이상한 값으로 고정된다. §3-④ 참조.
4. **4.7kΩ 풀업을 빼먹음** → `/sys/bus/w1/devices/`가 비어 있다. DS18B20은 이 저항 없이는 절대 안 잡힌다.
5. **릴레이 `NC`에 배선** → 평소에 붙어 있다가 명령하면 떨어지는, 정반대 동작이 된다. **`NO`를 쓴다.**
6. **릴레이 점퍼를 안 뽑음** → 릴레이가 제멋대로 붙었다 떨어졌다 한다. §3-② 참조.
7. **ADS1115 `ADDR`을 안 묶음** → `48`이 안 보이거나 다른 주소로 잡힌다. GND에 묶는다.
8. **ZY12PDN이 9V/12V 상태** → Babysitter가 연기를 내며 탄다. §3-① 참조.
9. **MQ-2 가스 센서를 온도 센서 옆에 붙임** → 이번 회로엔 가스 센서가 없지만, 나중에 추가할 때 주의. MQ-2 히터는 항상 뜨거워서(150mA@5V) 온도 측정을 오염시킨다.
10. **셀에 직접 인두질** → 홀더를 쓴다. 열이 셀 안으로 들어가면 그 자체가 이 프로젝트가 잡으려는 사고다.
11. **MLX90614 두 개를 주소 변경 없이 둘 다 연결** → 둘이 동시에 대답해 값이 뒤죽박죽이 된다. §3-⑤.
12. **MLX90614 두 개를 같은 곳에 겨눔** → 센서를 2개 쓴 의미가 없어진다. 시야가 겹치지 않게 벌린다.
13. **DS18B20을 어디에 붙였는지 기록 안 함** → 나중에 알아낼 방법이 없어 처음부터 다시 붙여야 한다.

## 8. KiCad로 회로도 여는 법

1. KiCad를 실행하고 `파일 → 프로젝트 열기`.
2. `hardware/mode1/cellguard_mode1.kicad_pro`를 고른다.
3. 왼쪽 목록에서 `cellguard_mode1.kicad_sch`를 더블클릭 → 회로도 편집기가 열린다.

**조작**

| 하고 싶은 것 | 방법 |
|---|---|
| 확대/축소 | 마우스 휠, 또는 `Ctrl` + `+` / `-` |
| 화면 전체 보기 | `Home` 키 |
| 이동 | 마우스 가운데 버튼 드래그 |
| 부품 정보 보기 | 부품 위에 마우스를 올리면 아래 상태바에 설명이 뜬다 |

**읽는 법**

- 이 회로도에는 **긴 배선이 없다.** 대신 부품 핀마다 짧은 선이 나오고 그 끝에 **육각형 이름표(글로벌 라벨)**가 붙어 있다.
- **같은 이름표끼리는 전부 한 줄로 이어져 있다는 뜻이다.** 예를 들어 `+3V3` 이름표가 붙은 자리는 전부 서로 연결돼 있다.
- 선이 어지럽게 교차하지 않아 초보자가 따라가기 쉽다.
- 파란 `X` 표시는 "여기는 일부러 아무것도 안 붙인다"는 뜻이다.

**심볼이 없다는 경고가 뜨면**: 나지 않아야 정상이다. 이 프로젝트는 `hardware/mode1/cellguard.kicad_sym`에 자체 심볼을 담고 있고, 회로도 파일 안에도 복사본이 들어 있다. 경고가 뜬다면 `hardware/mode1/` 폴더의 파일을 일부만 복사한 경우다 — 폴더째로 옮긴다.

**회로도를 고쳐야 한다면**: KiCad에서 직접 고치지 말고 `tools/gen_mode1_sch.py`를 고친 뒤 다시 실행한다. 이 회로도는 그 스크립트가 만든 것이라, 손으로 고친 내용은 다음 실행 때 날아간다.

```bash
python3 tools/gen_mode1_sch.py
```

> 이번 회로에는 **MQ-2 가스 센서와 음향 센서가 없다.** 가스는 보류했고 음향 센서는 아직 모델이 안 정해졌다. 그래서 데이터의 `gas_raw`와 `acoustic_raw`는 당분간 비어 있게 된다.
