# 셀가드 프로토타입 B2B SaaS 재설계 명세

## 목표

`설계 산출물/헬가드 프로토타입_v2.html`의 기존 화면 수, 기능, 텍스트와 사용자 흐름은 유지한다. 시각 언어와 정보 위계를 현대적인 B2B SaaS와 산업 안전 관제의 혼합형으로 재설계해, 배터리 상태와 즉시 행동을 빠르게 판단할 수 있게 한다.

## 시각 시스템

- 기본 배경은 연한 쿨그레이, 콘텐츠 표면은 흰색으로 통일한다.
- 브랜드 색은 네이비와 블루로 제한한다. 초록·주황·빨강은 정상·주의·경고·위험 같은 상태 의미에만 사용한다.
- 랜딩 첫 화면은 짙은 네이비 Hero로 시작한다. 전류 흐름, 셀, 보호막, 이상 파형을 추상화한 낮은 대비의 그리드·파형 그래픽을 Hero 및 핵심 섹션에만 사용한다.
- 과도한 네온, 글래스모피즘, 장식성 효과는 사용하지 않는다.
- 글자 체계는 페이지 제목, 섹션 제목, 본문, 보조 문구의 4단계로 단순화한다. 핵심 수치와 위험 상태는 본문보다 크게 표시하며, 라벨은 한국어를 우선한다.

## 화면 구조

### 랜딩

일반 SaaS의 익숙한 흐름을 적용한다.

1. 상단 내비게이션
2. 짙은 네이비 Hero와 제품 핵심 가치, 주요 CTA
3. 주요 기능
4. 실제 대시보드 화면 미리보기
5. 신뢰 지표
6. 전환 CTA

### 로그인 후 공통 레이아웃

- 고정 네이비 사이드바를 사용한다.
- 모든 화면에서 제목·설명·주요 버튼을 본문 상단의 같은 위치에 둔다.
- 검색, 필터, 표, 상세 패널은 기존 동작을 유지하되 위치와 여백을 공통 규칙으로 통일한다.
- 상세 패널, 필터 전환, 카드 선택에는 160~220ms의 짧고 절제된 모션을 적용한다.

### 대시보드

반복되는 작은 카드를 줄이고 다음 순서의 큰 섹션으로 구성한다.

1. **핵심 상황 영역**: 현재 연결 배터리, 위험 상태, 이상점수, 즉시 행동(측정 세션·상세 분석·릴레이 차단)을 한 영역에 배치한다.
2. **핵심 지표 영역**: 전압·전류·온도·SOC 4개 지표를 같은 크기와 형식으로 표시한다. 현재값과 변화량·임계 근접 정보를 함께 제공한다.
3. **분석 및 사건 영역**: 대형 추세 차트를 우선 배치하고 최근 이벤트와 상세 분석 진입점을 인접시킨다.

위험 발생 시 상단 핵심 상황 영역, 온도/점수 지표, 해당 차트 구간과 이벤트를 함께 강조한다.

## 차트와 상태

- 차트는 현재보다 크게 배치하고 정상·주의·경고·위험 구간을 배경 밴드로 표현한다.
- 현재값, 임계값, 상승 추세가 하나의 화면에서 읽히도록 기준선·강조점·상태 색을 조합한다.
- 상태를 배지에만 의존하지 않고 색 면적, 아이콘, 추세 그래프를 함께 사용한다.
- 로딩, 데이터 없음, 연결 끊김, 측정 중 상태를 실제 서비스의 빈 상태/진행 상태로 설계한다.

## 반응형 규칙

- 데스크톱은 고정 사이드바와 다중 열 관제 구조를 유지한다.
- 태블릿은 사이드바를 접고, 핵심 지표를 2열로 전환한다.
- 모바일은 하단 내비게이션과 단일 열 흐름으로 바꾸며 위험 상태·현재 이상점수·알림·릴레이 차단을 우선 노출한다.

## 구현 및 검증 범위

- 대상 파일: `설계 산출물/헬가드 프로토타입_v2.html`
- 번들 안에 들어 있는 실제 템플릿/자산을 변경해 단독 HTML로 열었을 때도 유지한다.
- 기존 클릭, 필터, 모달, 상세 패널, 상태 전환 등 상호작용을 보존한다.
- 데스크톱과 모바일 너비에서 렌더링을 확인하고, 기존 동작의 오류가 없는지 검증한다.
- 설계 산출물 변경은 `PLAN.md`의 작업 로그로 기록하지 않는다. 완료 시 대상 파일과 이 명세만 별도 로컬 커밋한다.
