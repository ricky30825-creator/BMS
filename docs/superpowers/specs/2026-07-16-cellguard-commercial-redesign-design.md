# 셀가드 프로토타입 상용 SaaS 디자인 개선 설계

## 목적

`설계 산출물/헬가드 프로토타입_v2.html`의 화면 기능과 흐름은 유지하면서, 데모형·장식적인 인상을 줄이고 장기 운영형 B2B SaaS 관제 서비스로 보이도록 시각 체계를 재설계한다.

사용자가 선택한 방향은 **A: 신뢰 중심 · 정돈된 엔터프라이즈**다.

## 범위

- 랜딩, 인증, 일반 사용자 관제, 관리자 관제, 목록, 상세, 설정, 모달에 공통 디자인 규칙을 적용한다.
- 기존의 라우팅, 예시 데이터, 상호작용과 표시 기능은 변경하지 않는다.
- 기능 요구사항이나 문구의 의미를 추가·삭제하지 않는다.
- 별도 프레임워크 전환, 파일 분리, 신규 외부 라이브러리 추가는 하지 않는다.

## 시각 체계

### 색과 표면

- 앱 배경은 `#F7F9FC`, 주요 표면은 흰색, 테두리는 옅은 블루그레이를 사용한다.
- 네이비(`#122033`)는 좌측 내비게이션과 밀도 높은 운영 컨텍스트에 한정한다.
- 브랜드 파랑(`#2563EB`)은 주요 행동, 선택 상태, 핵심 데이터 강조에만 사용한다.
- 녹색·주황·적색은 정상·주의·위험 상태에만 사용한다. 장식 색으로 재사용하지 않는다.

### 타이포그래피와 밀도

- 기존 Pretendard를 유지한다.
- 페이지 제목, 보조 설명, 카드 제목, 수치, 메타 정보를 5단계 계층으로 명확히 나눈다.
- 카드의 큰 숫자는 탭형 숫자 폭과 충분한 여백으로 읽기 쉽게 만들며, 설명 텍스트는 대비를 낮춘다.
- 불필요한 점무늬·그라데이션·과도한 그림자를 제거하고, 카드·섹션 간 간격을 일관되게 한다.

### 컴포넌트

- 사이드바: 제품명, 역할/상태, 메뉴의 선택 상태를 일관되게 표시한다.
- 상단 바: 현재 위치, 운영 상태, 프로필/행동을 구분해 배치한다.
- 카드: 흰 표면, 얇은 테두리, 10~12px 모서리, 절제된 그림자를 공통으로 사용한다.
- 버튼·필터·탭: 기본/보조/위험 행동을 구분하고, 선택 상태는 파랑으로 한정한다.
- 표·리스트: 행 구분과 밀도를 개선하되, 위험 행만 낮은 채도의 상태 배경으로 강조한다.
- 모달: 배경 차단, 제목·영향 설명·행동 버튼의 우선순위를 분명히 한다.

## 화면별 적용

- 랜딩: 신뢰 신호, 제품 가치, 주요 행동을 명확히 구획하고, 제품 화면 미리보기는 과한 장식 대신 실제 관제 정보 밀도를 보여준다.
- 로그인/인증: 브랜드 요소는 최소화하고 입력과 다음 행동에 집중시킨다.
- 일반 사용자: 현재 위험도, 활성 알림, 장비 상태, 추세 순으로 정보 계층을 통일한다.
- 관리자: 일반 사용자와 같은 토큰을 공유하되, 사용자·자산·감사·서비스 상태의 목록/필터 가독성을 우선한다.
- 모바일: 기존 반응형 동작을 보존하면서 여백과 터치 대상 크기를 유지한다.

## 구현 및 검증

- 번들 안의 템플릿 CSS와 공통 인라인 스타일 토큰을 우선 교체해 전 화면의 일관성을 확보한다.
- 특정 화면만 필요한 보정은 해당 화면의 기존 인라인 스타일 범위에서 최소한으로 적용한다.
- 수정 후 HTML을 브라우저에서 열어 랜딩, 일반 사용자 대시보드, 관리자 화면, 모달의 표현과 기존 클릭 동작을 확인한다.
- 원본을 바꾸기 전에 `archive/` 아래에 백업을 남기고, HTML 구조와 JavaScript가 손상되지 않았는지 점검한다.

## 성공 기준

- 첫 화면이 따뜻한 데모 페이지가 아닌 신뢰감 있는 B2B 운영 제품처럼 보인다.
- 어느 화면에서나 같은 색·여백·버튼·카드 규칙을 인식할 수 있다.
- 위험 상태는 눈에 띄지만, 정상 상태 화면은 차분하게 유지된다.
- 기존 프로토타입의 화면 진입과 상호작용은 유지된다.
