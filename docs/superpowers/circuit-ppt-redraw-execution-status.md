- PowerPoint 앱에서의 표시와 실물 전기 동작은 별도 검증하지 않음. 코드·하드웨어 계약은 변경하지 않음.
- PPTX와 백업은 기존 제외 정책을 유지하고 Git에 추가하지 않음. 이 기록만 로컬 커밋하며 원격 push는 하지 않음.

## 통합 전체 회로 추가

- 후속 사용자 요청에 따라 기존 1~4페이지를 유지하고 5페이지에 통합 회로를 추가.
- 큰 헤더·설명 영역을 제외하고 부품 모델·핀·저항값만 표시. 전원·접지·I²C·1-Wire·SPI·릴레이 제어·전력 경로를 실제 native line으로 이어 글로벌 라벨 대체 연결을 제거.
- 기존 4페이지는 PPTX 내 slide XML 및 slide relationship의 바이트 비교로 변경 없음 확인. 추가 전 파일은 `설계 산출물/아카이브/회로도_4페이지_통합추가전_20260929.pptx`에 보관.
- 검증: 최종 5페이지 패키지·크기·재가져오기 통과, 전 페이지 렌더링 및 5페이지 시각 확인. 5페이지는 native shape 453개, 이미지 0개. 배선 기록 기준 서로 다른 색상 네트의 수평/수직 선이 같은 구간을 공유하는 중첩 0건.
- 미사용 핀·기성 모듈 내부 회로는 생략. SOURCE_P는 실제 수동 교체 체결점이며 두 양극은 영구 병렬하지 않음. PowerPoint 앱·실물 회로 검증 범위는 기존과 동일.
