- 기존 4페이지는 PPTX 내 slide XML 및 slide relationship의 바이트 비교로 변경 없음 확인. 추가 전 파일은 `설계 산출물/아카이브/회로도_4페이지_통합추가전_20260929.pptx`에 보관.

- 미사용 핀·기성 모듈 내부 회로는 생략. SOURCE_P는 실제 수동 교체 체결점이며 두 양극은 영구 병렬하지 않음. PowerPoint 앱·실물 회로 검증 범위는 기존과 동일.

## 공통 전원·접지 레이블 처리

- 사용자 요청으로 5페이지의 공통 전원·접지 배선을 `+3V3`, `+5V`, `GND` 레이블로 변경. 신호 전원·코일 전압을 구분하고 ADC ADDR, FSR 분압 하단, 전원장치·부하의 접지를 포함.
- I²C·1-Wire·SPI·릴레이 제어·충방전 경로와 셀 BAT− 귀환은 직접 배선을 유지. 1-Wire 버스는 전원 레이블과 겹치지 않도록 옆으로 이동.
- 검증: 5페이지 수·PPTX 패키지·재가져오기 통과. 최종 전 페이지 렌더링, 5페이지 시각 확인. 1~4페이지 slide XML·relationship 변경 없음, 5페이지 이미지 없음 확인.
- 변경 전 5페이지 파일은 같은 산출물 폴더의 `아카이브/회로도_통합직접배선_전원레이블변경전_20260929.pptx`에 보관.

## 5페이지 가독성·보조배터리 수정 (2026-09-30)

- 라즈베리파이 심벌을 키우고 4채널 릴레이 심벌을 줄였다. MLX90614와 DS18B20은 각각 대표 심벌 1개로 표시하되 실제 수량 `×2`(I²C 0x5A/0x5B), `×3`(모드 2에서 실온 1개 사용)을 표기했다.
- 외부 셀·USB 입력 심벌 대신 보조배터리 1개를 표시했다. 5페이지는 보조배터리 VBUS가 SOURCE_P에 단독 체결된 모드 2 연결 상태이며, ZY12PDN·Babysitter와 릴레이의 모드 1 경로 부품은 통합 회로의 구성요소로 남겼다. 공통 전원·접지는 레이블, 신호·제어·부하 경로는 직각 native line으로 표현했다.
- 정본 `hardware/combined/cellguard_combined.kicad_sch`의 KiCad 내보내기 넷리스트와 대조했다. SOURCE_P→INA226 IN−/VBUS, INA226 IN+→CH3 COM→CH3 NO/CH4 COM, CH2 NO/CH4 NO→BW150 LOAD+, Pi I²C·1-Wire·SPI·GPIO5/6/13/19 연결을 확인했다. KiCad ERC는 오류 0건·경고 0건이었다. 대표 센서 심벌은 실제 병렬 장착 수를 줄인 회로 변경을 뜻하지 않는다.
- 최종 파일은 5페이지·4:3·PPTX 패키지 및 Artifact Tool 재가져오기 검사를 통과했다. 전 페이지를 다시 렌더링해 5페이지를 시각 확인했다. 1~4페이지 slide XML·relationship은 수정 전 파일과 바이트 동일하고, 5페이지는 native shape 338개·이미지 0개다.
- 직전 파일은 `설계 산출물/아카이브/회로도_통합회로_센서전원수정전_20260930.pptx`에 보관했다. PowerPoint 앱에서의 편집 동작과 실물 전기 동작은 검증하지 않았다.

## 5페이지 블록·배선 겹침 정리 (2026-09-30)

- Babysitter I²C 두 선을 라즈베리파이 위쪽 빈 공간으로 우회하고, GPIO→릴레이 제어선은 라즈베리파이 아래쪽으로 이동했다. 릴레이 전원 레이블은 아래로, FSR 10k 분압 저항은 보조배터리 블록 밖으로 옮겼다. 선의 양끝 연결 대상과 부품 수는 유지했다.
- PPTX의 native 선과 12개 부품 블록 좌표를 검사해 블록 내부를 통과하는 배선 0건을 확인했다. 5페이지를 다시 렌더링해 육안 확인했고, 1~4페이지 slide XML·relationship은 수정 전과 바이트 동일하다. 패키지·크기·5페이지 수·Artifact Tool 재가져오기 검사를 통과했다.
