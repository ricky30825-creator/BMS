유해가스(수소·일산화탄소·VOC) 센서 추가 검토 보고서

대상: AI 배터리 열폭주 조기감지 관제 시스템 (프로젝트 7241ba62)
작성일: 2026-06-20 · 요청: "다른 BMS처럼 수소 등 유해가스 센서를 넣는 게 어떨지 + 디바이스마트 제품 + 추가 센서 검토"

결론 — 강력 추천 ✅

가스 센서 추가는 이 프로젝트의 핵심 차별성과 정확히 맞습니다. 리튬이온 배터리는 열폭주 직전, 온도가 크게 오르거나 불이 나기 전에 먼저 가스(수소·CO·전해액 증기)를 방출(off-gas)합니다. 즉 가스 감지는 우리가 내세우는 "임계치 차단(사후)이 아닌 정상패턴 학습 기반 사전 예측"을 물리 센서 레벨에서 한 번 더 보강해 주는, 가장 빠른 전조 신호입니다.

실제로 ESS·전기차 업계(센시리온, Winsen, 한전 등)가 이미 수소 off-gas 센서를 열폭주 조기경보의 1차 신호로 채택하고 있습니다. AI 입력 특징에 가스 농도/변화율을 추가하면 탐지가 더 빨라지고 오탐도 줄어듭니다.

1왜 가스 센서인가 — 열폭주 전조의 과학

리튬이온 셀 내부에서 이상 발열 반응이 시작되면, 전해액이 분해되며 다음 순서로 신호가 나타납니다:

① 미세 전압/내부저항 변화 → ② off-gas 방출(수소 H₂, CO, CO₂, 전해액 VOC 증기) → ③ 셀 스웰링(팽창)·압력 상승 → ④ 표면 온도 급상승 → ⑤ 연기/벤팅 → ⑥ 발화

현재 시스템은 전압·전류·온도·SOC·절연저항(①·④)를 봅니다. 여기에 ②(가스)를 추가하면 온도가 오르기 전 단계를 잡을 수 있어 경보 시점이 수십 초~수 분 앞당겨집니다.

  • 방출 가스 구성: 화재 시 CO₂·CO 비중이 가장 큼, 초기 이상 반응에서는 H₂(수소)가 가장 먼저 공기 중 농도 변화로 나타남 → H₂가 가장 빠른 조기 신호로 평가됨.
  • 전해액(EC/DMC/EMC) 증기는 VOC(휘발성 유기화합물)로 검출 가능.
  • 권장 전략: 단일 가스가 아니라 가스 농도 + 변화율(rate) + 가스 종류 조합으로 판단하면 오탐이 크게 줄어듦 (문헌 공통 결론).

2디바이스마트 추천 제품

가격 안내: 디바이스마트 상품 페이지는 가격을 JavaScript로 표시해 자동 추출이 막혀, 아래 가격은 시중 통상가 기준 참고치입니다. 정확한 금액·재고는 각 링크에서 확인해 주세요.

2-1. 라즈베리파이에 바로 붙는 1순위 — BME680 (I²C 올인원)

제품측정인터페이스참고가비고
BME680 (CJMCU-680) 최우선 VOC 가스 + 온도 + 습도 + 기압 I²C / SPI ~8,000–15,000원 라즈베리파이 I²C에 직결(기존 INA·아키텍처와 동일 방식). VOC로 전해액 증기 감지 + 습도·기압은 누설/스웰링 보조 신호로 보너스.
왜 1순위? 우리 에지는 이미 I²C/1-Wire 기반입니다. BME680은 아날로그-디지털 변환기(ADC) 없이 I²C 핀에 바로 붙고, 한 모듈로 VOC·온도·습도·기압 4가지를 줘서 배선·코드가 가장 깔끔합니다.

2-2. 수소(H₂) 전용 — 시연 효과가 확실한 1차 신호

제품측정/범위방식참고가비고
MQ-8 수소 센서 모듈 [SEN0133] 권장 H₂ 100–1000ppm 반도체식(MOS), 아날로그 ~3,000–6,000원 매우 저렴, H₂ 민감(알코올·LPG에는 둔감). 아날로그 출력 → 라즈베리파이엔 ADC 필요.
ME3-H2 수소 센서 정밀형 H₂ (전기화학식) 전기화학식 ~30,000–50,000원 저전력·고정밀이나 가격↑·수명 한정. 시제품엔 과할 수 있음.

2-3. 함께 고려할 가스

제품측정/범위참고가비고
MQ-7 일산화탄소(CO) [SEN0132]CO 20–2000ppm~3,000–6,000원화재 단계 비중 큰 CO 감지. 아날로그.
MQ-2 가연성가스/연기LPG·연기·가연성가스~2,000–5,000원벤팅/연기 단계 감지용. 아날로그.
디바이스마트 가스/산소/VOC 센서 카테고리——전체 라인업 둘러보기.
MQ 시리즈 주의점 (반도체식 공통)
  • 아날로그 출력 → 라즈베리파이는 아날로그 입력이 없으므로 MCP3008 같은 SPI ADC(~2,000–4,000원)가 추가로 필요. (모듈의 디지털 임계 출력 D0만 쓰면 ON/OFF만 가능)
  • 히터가 항상 가열(약 150mA) → 소비전력 큼, 예열 시간 필요, 시간에 따른 캘리브레이션 드리프트·교차감도 존재. 정확한 ppm보다 "변화율/추세"로 쓰는 게 적합.
  • 가연성 가스 환경용으로 설계된 부품이지만, 배선 안전과 환기는 실험 시 유의.

3추가로 검토할 다른 센서

off-gas 외에, 열폭주 단계별로 의미 있는 물리 신호를 더 잡을 수 있는 센서들입니다. 우선순위 순:

① 셀 스웰링/팽창 — 힘·압력 강력 추천

전해액 기화로 셀이 부풀어 오르는 스웰링은 대표적 물리 전조. 셀 뒤에 로드셀 / FSR(힘센서)를 깔아 팽창 압력을 측정.

디바이스마트: 기압/무게/로드셀/Flex 카테고리

② 연기·미세먼지(PM2.5) 권장

벤팅·발연 단계 확정 신호. GP2Y1010 먼지센서 또는 PMS7003(UART) 등.

화재 직전 escalation 확인용 (가스보다 늦은 신호).

③ 습도 권장

전해액 누설/결로 감지. BME680에 이미 포함되어 별도 비용 없이 확보 가능.

④ 인클로저 기압 선택

밀폐 케이스 내 가스 발생 시 압력 상승. BME680 기압계로 대체 가능.

⑤ 불꽃(IR Flame) 센서 선택

최종 발화 단계 즉시 감지. 차단(Kill-Switch) 트리거 백업용.

이미 보유 중

전압·전류(INA219/226), 접촉/IR 온도(DS18B20·IR), SOC(bq27441), 절연저항. ✔

4시스템 통합 방안

센서를 넣으면 데이터 스키마·AI·대시보드에 다음 변경이 따라옵니다 (요청 시 정식 반영).

센서 JSON 스키마 추가 필드 (battery-raw-metrics)

// 에지가 Raw 값만 전송하는 기존 규약 유지
{
  "gas_h2_ppm": 12,        // MQ-8 (ADC 환산)
  "gas_co_ppm": 3,         // MQ-7 (선택)
  "voc_ohm": 152000,       // BME680 가스 저항 (낮을수록 VOC↑)
  "humidity_pct": 41.2,    // BME680
  "pressure_hpa": 1006.4,  // BME680
  "swelling_n": 0.8        // 로드셀/FSR (선택)
}
  • AI 특징(F-VTQMVE/S-WKCPVK): 기존 7개 특징에 gas_rate(dGas/dt), voc_drop 등을 추가하면 LSTM-AutoEncoder가 가스 전조까지 학습.
  • Kafka: 토픽 구조 변경 없음 — battery-raw-metrics 페이로드 필드만 확장. 가스 임계 초과는 battery-events로 발행.
  • 대시보드(S-OFKBJC): 게이지에 "가스 농도(H₂/VOC)" 카드 1개 추가, 신호등에 가스 경보 반영.
  • 에지 배선: BME680 = I²C 직결 / MQ 계열 = SPI ADC(MCP3008) 경유 / 로드셀 = HX711 모듈.

5권장 구성 (시제품 기준)

티어구성합계(참고)이유
최소(MVP) BME680 1개 ~1.5만원 I²C 직결, 배선 0추가, VOC+습도+기압 한 번에. "가스 추가" 목적 달성 최단경로.
권장 ★ BME680 + MQ-8(H₂) + MCP3008(ADC) ~2.3만원 H₂ 전용 1차 신호 + VOC 베이스라인 동시 확보. 시연 임팩트 + AI 특징 다양성 최적.
풀 권장 + MQ-7(CO) + 로드셀(HX711) + PM2.5 ~4–5만원 off-gas→스웰링→연기 단계별 신호 완비. 논문/발표용 완성도.

개인 추천: 「권장 ★」 구성. 라즈베리파이 아키텍처와 충돌 없고, 가격 부담이 적으며, "온도 오르기 전에 가스로 먼저 잡았다"는 시연/발표 스토리가 명확합니다.

+추가 센서 — 2차 검토

1차 보고 이후 추가로 조사한, 열폭주 탐지에 실제로 가치가 큰 센서들입니다. 우선순위 순으로 정리합니다.

① CO₂ NDIR 센서 — MH-Z19B 강력 추천

CO₂는 화재·열폭주 가스 중 비중이 가장 큰 축입니다. MH-Z19B는 NDIR(비분산적외선) 방식이라 MQ 계열(반도체식)보다 드리프트·교차감도가 훨씬 적고 정확합니다.

  • 범위 0–2000/5000ppm, 3.6–5V, UART/PWM 출력 → 라즈베리파이 직결(ADC 불필요)
  • VOC(BME680) + H₂(MQ-8) + CO₂(MH-Z19B) 조합이면 off-gas 3대 신호를 안정적으로 커버. 참고가 ~2–3만원.

② 음향방출(AE)/초음파 센서 — 차별화 끝판왕 도전적

셀 내부에서 가스 기포가 생기고 분리막이 균열되면 탄성파(소리)가 발생합니다. AE 센서는 이를 비침습으로 잡아 가스가 외부로 새어 나오기도 전에 전조를 감지합니다 — 가장 빠른 신호 축에 듭니다.

  • 국내에 음향 기반 ESS 배터리 화재 조기감지 특허(KR102254734B1)가 존재 — 검증된 접근.
  • 전용 AE 센서는 고가·전문 장비. 시제품에선 마이크/초음파 트랜스듀서로 벤팅 "쉭" 소리·기포음을 대체 감지하는 수준으로 시도 가능.
  • 신호처리 난이도가 높음 → "추가 점수/발표 임팩트용 선택지"로 권장.

③ 열화상 어레이 — MLX90640 (32×24) 업그레이드

기존 단일점 IR을 면적(32×24) 열화상으로 업그레이드 → 셀 표면의 hotspot 위치까지 추정. -40~300°C, ±2°C, 라즈베리파이 호환.

단일 온도 → 열분포 패턴을 AI 특징으로 쓸 수 있음.

④ IMU/가속도 (MPU6050) 선택

낙하·충격·기울기 감지. 물리 충격은 내부 단락(열폭주 유발 원인)의 대표 트리거이고, 케이스 파열도 진동으로 포착 가능. 매우 저렴(~2–3천원).

2차 검토 요약: off-gas를 더 정확히 보강하려면 CO₂(MH-Z19B)가 가성비 1순위. 발표/논문 차별화를 노린다면 음향(AE/초음파)이 가장 임팩트가 크고, 온도 정밀도를 높이려면 MLX90640 열화상 어레이로의 업그레이드를 권합니다.
