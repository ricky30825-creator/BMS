리튬이온·리튬폴리머 배터리 열폭주 데이터 분석 보고서

대상: AI 배터리 열폭주 조기감지 관제 시스템 (프로젝트 7241ba62)
작성일: 2026-06-20 · 요청: "배터리가 터지는 엣지 상황·이상 데이터를 직접 테스트하긴 위험하니, 18650/리튬폴리머 열폭주 데이터를 웹에서 분석해 보고서로 만들어줘"

요약 — 직접 폭주시키지 않고도 "정답 신호"를 확보할 수 있습니다 ✅

전 세계 연구진이 이미 18650·파우치 셀을 실제로 열폭주시키며 전압·온도·가스를 초 단위로 계측한 공개 데이터·논문이 충분히 있습니다.

이 보고서는 그 실측값을 모아 ① 열폭주가 어떤 순서로 어떤 신호를 내는지(전기·온도·가스 + 외부 물리 신호: 팽창·소리·연기), ② 우리 AI의 7개 특징(V_drop·dT_dt 등)에 각 단계가 어떻게 찍히는지, ③ 그래서 직접 만들 수 있는 합성 이상(anomaly) 데이터의 시그니처가 무엇인지를 정리합니다.

핵심 결론: 우리는 위험한 실폭주 실험 대신, 공개 데이터셋 + 아래 시그니처 기반 합성 데이터로 LSTM-AutoEncoder의 이상탐지 성능을 검증·튜닝할 수 있습니다.

1왜 실측 대신 "공개 데이터 + 합성 데이터"인가

실폭주 실험은 시제품 단계에서 부적절합니다. 18650 한 셀의 열폭주 피크 온도는 290~730 ℃에 이르고, 셀 내부 가스가 분출(벤팅)된 뒤 24초 만에 발화한 실험 보고가 있습니다. 독성 가스(CO·HF)·분출물·화재 위험이 커서 통제된 방폭 시설 밖에서는 재현해선 안 됩니다.

대신 두 가지를 결합합니다.

① 공개 실측 데이터셋

NASA·Sandia·ORNL 등이 실제 셀을 파괴 시험하며 기록한 전압·전류·온도·하중 시계열. 5장에 링크 정리.

② 시그니처 기반 합성 데이터

아래 실측 거동(전압 급락·온도 상승률 폭증·가스 방출 순서)을 정상 시계열 위에 주입해 "주의→경고→위험" 라벨 데이터를 직접 생성. 6장 참조.

2열폭주는 어떤 순서로 신호를 내는가 (4단계 메커니즘)

리튬이온 셀의 열폭주는 갑자기 터지는 것이 아니라, 측정 가능한 전조가 순차적으로 나타납니다. 문헌 공통으로 ①초기 → ②가스 감지 → ③반응 가속 → ④폭주 후의 4단계로 구분합니다.

  • ① 초기 / 미세 이상 (T < ~90 ℃) SEI 피막 분해 시작. 전압·내부저항의 미세 변화가 가장 먼저(거의 즉각) 나타남. 온도 상승률은 아주 완만 — T1은 보통 0.01 ℃/min 상승률을 넘는 시점으로 정의.
  • ② 가스 방출 / 안전밸브 개방 (~140–160 ℃) 전해액이 끓어 셀이 부풀고(스웰링) 안전밸브가 열리며 off-gas 분출. 수소(H₂)가 가장 먼저 공기 중에 검출됨 → 가장 빠른 1차 경보 신호(온도 급상승 수십 초~수 분 전).
  • ③ 반응 가속 / 트리거 (T2 ≈ 140–186 ℃) 분리막 용융·내부 단락. 이 임계점 이후 온도가 지수적으로 상승해 어떤 냉각으로도 멈출 수 없음. dT/dt가 폭증하고 전압이 급락하기 시작.
  • ④ 열폭주 / 발화 (T3 ≈ 290–730 ℃) 대량 가스·전해액 분출, 전압 0 V로 붕괴, 연기·화염. 18650 기준 발화는 폭주 개시 약 24초 후 관측.
우리 시스템의 의미: 현재 보는 전압·전류·온도·SOC·절연저항은 ①·③·④를 잡습니다. ②(가스)는 가스 센서 추가 검토 보고서에서 다룬 대로 보강하면 경보를 수십 초~수 분 더 당길 수 있습니다.

3-2. 전압 거동 — 가장 빠르고 보편적인 전기 신호

  • 정상/밸브개방 직후까지는 전압이 상당 시간 안정하게 유지됨 (한 LFP 실험에선 12,500–17,000초 구간 안정).
  • 내부 단락이 진행되며 전압이 급락, 폭주 격화 구간에서 0 V로 붕괴.
  • 핵심: 전압은 거의 모든 고장 유형에 즉각 반응하며, 전압 급락이 표면 온도 급상승보다 앞선다. → V_drop·V_delta 특징의 근거.

4배터리가 "터질 때" 내는 외부(물리) 시그널

전압·온도·가스 외에도, 셀이 폭주로 가는 동안 외부로 관측 가능한 물리 신호가 순차적으로 나옵니다. 상당수는 비접촉·저가 센서로 잡히고, 일부(팽창·음향)는 표면 온도보다 더 빨라 멀티모달 조기경보의 핵심 채널로 주목받습니다.

4-1. 외부 신호의 출현 순서 (이른→늦은)

  • ① 팽창·스웰링 / 내부 압력 상승 (가장 이른 기계 신호) 가스 발생으로 셀 케이스가 부풀고 내부 압력이 오름. 내부 압력 피크는 온도 피크에 선행하며, 압력 도함수의 변곡점을 잡으면 안전밸브 개방 최대 30분 전 경보 가능. NMC 과충전은 5단계, LFP는 2단계의 힘(force) 변화를 보임.
  • ② 음향(소리) — 안전밸브 개방·파열음 압력이 임계에 도달해 밸브가 열리거나 파우치가 터질 때 날카로운 벤팅음 발생. 주파수 0–8000 Hz(주로 3000 Hz 이하). 음향은 물리 변형에 직결돼 온도·압력 모니터링보다 약 2배 빠른 경보가 가능(딥러닝 분류 정확도 93.9% 보고).
  • ③ 가스·냄새 (off-gas + 자극적 전해액 냄새) 수소(H₂)가 최선행(3-3절). 외부로는 자극적인 전해액 증기(VOC) 냄새로도 나타남. 온도 급상승 수십 초~수 분 전.
  • ④ 연기·입자 (후기 신호) 고분자(분리막·바인더) 분해·연소로 발생. 한 실험에서 벤팅 후 약 300초에 연기가 챔버를 가득 채움. 입자 분출(particle venting) 동반.
  • ⑤ 표면 발열 핫스팟 → 화염·빛 (최종) 표면 국소 핫스팟이 적외선으로 먼저 보이고, 마지막에 화염·강한 발광. 발화는 폭주 개시 약 24초 후(3장).

AI 연계: 이들 외부 신호는 LSTM-AE의 추가 입력 특징으로 합치거나, 별도 채널의 확인/거부(veto) 신호로 써서 릴레이 인터락 결정을 한 번 더 보강할 수 있습니다(예: "전압·온도 이상 + 벤팅음 동시 검출 → 즉시 차단").

합성 데이터 생성 권장 절차: ① NASA 정상 시계열을 베이스로 → ② 특정 시점부터 V_drop 음의 드리프트·dT/dt 지수 항을 주입 → ③ 단계 전환 시점에 위 등급 라벨 부여 → ④ 재구성 오차(MSE)가 등급과 단조 증가하는지로 모델 검증. 여러 SOC·모드(1/2/3)별로 변주하면 일반화도 함께 점검됩니다.

7다음 단계 제안

  • NASA 데이터로 정상 베이스라인 학습 — LSTM-AE를 "정상"에 먼저 수렴시킨 뒤 임계 MSE를 0.3/0.6/0.8 등급에 매핑.
  • ORNL/Sandia 고장 데이터로 테스트셋 구성 — 실제 고장 + 심각도 라벨로 오탐·미탐을 정량 평가.
  • 6장 시그니처로 합성 이상 주입 — 실폭주 없이 "주의→경고→위험" 전이 시계열을 대량 생성해 학습/검증 보강.
  • 가스 채널 합류 검토 — H₂가 ②단계의 최선행 신호이므로, 가스 특징을 추가하면 경보 시점이 더 앞당겨짐(가스 센서 보고서 연계).
확인 필요(사용자 판단): ① 우리 실측 대상 셀의 정확한 화학종(NMC/LFP/LiPo)과 ② 모드별 정상 운용 SOC 범위를 알려주시면, 합성 데이터의 온도·전압 파라미터를 그 셀에 맞춰 더 정확히 보정하겠습니다.
