현재 센서 구성은 "온도가 오른 뒤"를 본다

우리 시스템이 수집하는 지표는 전압·전류·전력·SOC·온도(접촉/IR)·절연저항이다. 모두 의미 있지만, 대부분 전조의 중·후반에서야 뚜렷이 변한다.

  • 전압·내부저항 미세 변화는 잡기 어렵고, 실제 경보는 온도 급상승(④)에 의존하는 경향
  • 온도가 오른 시점은 이미 SEI 분해·부반응이 진행된 뒤 → 대응 시간이 짧음
  • LSTM-AutoEncoder가 정상패턴 이탈을 학습해도, 입력 신호 자체가 늦으면 경보도 늦다
  • → 온도보다 앞선 물리 신호(내부 미세 파괴·기포·벤팅)를 잡을 채널이 필요

우리는 "밀폐 팩"이 아니라 "개방 공간"에서 측정한다

대상은 개방(open) 공간의 18650 셀·USB 보조배터리다. ESS·EV처럼 셀이 밀폐 팩 안에 있지 않다. 이 차이가 센서 선택을 가른다.

  • 가스센서: 밀폐 팩은 off-gas가 축적되어 ppm이 치솟지만, open에서는 즉시 확산·희석 → 센서 도달 농도↓, 거리·기류에 좌우 → "온도보다 먼저"의 강점이 약화
  • 음향(벤팅음): 매질이 공기 중 음파라 거리·개방 여부의 영향이 작고, 실제로 MW급 ESS 현장에서 검증된 방식
  • 결론: open 환경에서는 가스보다 음향이 비용 대비 효용·재현성에서 유리

음향 기반 감지는 두 갈래다 — 듣기(AE) vs 거리측정

"음향 센서"는 크게 두 방식으로 나뉜다. 우리가 원하는 것은 소리를 듣는(수동) 방식이다.

(A) 벤팅·안전밸브 파열음 — 수동 마이크
셀이 부풀다 안전밸브가 터질 때 나는 "쉭/팡" 소리를 마이크로 청취. open 공간에 적합, 라즈베리파이 직결 가능. 단 벤팅 단계(⑤)라 상대적으로 늦은 신호.
(B) 내부 균열·기포 탄성파 — 접촉 AE(음향방출)
셀 내부에서 분리막 균열·가스 기포가 생길 때 발생하는 초음파(~100kHz↑)를 셀 표면에 붙인 압전 소자로 포착. 가스가 외부로 새기 전에 감지 → 가장 빠른 축. 신호처리·하드웨어 난이도 높음.
⚠ 흔한 오해 정정
시중의 "초음파 센서(HC-SR04)"는 펄스를 쏘고 반향 시간을 재는 거리측정(소나) 장치로, 소리를 듣는 센서가 아니다. 전조음 청취 목적에는 부적합하며, 굳이 쓴다면 스웰링(팽창) 거리 측정용으로만 의미가 있다.
정리
전조음 탐지 = 수동 청취형(마이크 / AE 압전).
거리측정 초음파 모듈은 별개 용도.

신뢰성 ③ — 음향은 이미 배터리 진단의 검증된 모달리티다

화재 경보뿐 아니라 배터리 내부 상태 진단에도 음향(초음파)이 학계에서 정립되어 왔다. 신호의 물리적 근거가 탄탄하다는 의미다.

  • 리튬 삽입·가스 발생으로 셀 내부 밀도·탄성률이 변하면 음속·반향(ToF)이 변한다 → 비침습 진단 가능
  • 이 원리는 SOC·SOH 추정에 활용되며 다수 후속 연구로 확장
  • 즉 음향은 "실험적 시도"가 아니라 물리적으로 검증된 신호원 → 우리 AI 입력 특징으로 정당성 충분

선택 가능한 옵션 — 회의에서 결정할 사항

open 환경·음향 도입은 합의됨. 아래 음향 구성(A/B/C)과 가스센서 부가 여부를 결정하면 된다.

옵션 A
MEMS 마이크만
  • 저비용, 라즈베리파이 직결
  • 특허·grid 논문이 검증한 방식
  • 벤팅(⑤) 단계라 다소 늦은 신호
  • 난이도 낮음 / 빠른 구현
옵션 B
접촉 AE 피에조만
  • 가장 빠른 내부 전조 신호
  • 보조MCU+고속ADC 필요
  • 신호처리 난이도 최상
  • open에서도 유효(접촉식)
옵션 C · 권장
A + B 동시
  • 내부 탄성파 → 벤팅음 단계별 커버
  • 발표·논문 차별화 "끝판왕"
  • 난이도 높음(감수 합의됨)
  • 멀티모달 융합 = 오탐↓
부가 결정 — 가스센서 : open 환경이라 효용 제한. ⓐ 제외 하거나, ⓑ BME680만 두어 VOC·습도·기압을 "변화율 보조 신호"로만 활용(저비용·I2C 직결). MQ 계열(ADC·예열 부담)은 비권장.
권장: 옵션 C + 가스센서는 BME680 보조(ⓑ) — 음향 멀티모달을 핵심 신규 신호로, 가스는 저비용 보조로. 최종 결정은 회의 합의에 따름.
