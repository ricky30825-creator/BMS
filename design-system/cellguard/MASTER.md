## 1. 제1원칙 — 상태색은 크롬에 쓰지 않는다

계약서는 4단계 등급(정상·주의·경고·위험)을 고정 요구사항으로 못박는다. 등급 판정이 화면에서 즉시 읽히는 것이 이 제품의 존재 이유다.

**따라서 녹·황·주황·적은 오직 등급 표시에만 쓴다.** 배경, 테두리, 사이드바, 기본 버튼, 링크, 포커스 링 어디에도 쓰지 않는다. 크롬이 상태색을 쓰면 사용자는 "저 녹색이 정상이라는 뜻인가, 그냥 배경인가"를 매번 판단해야 한다.

- 크롬 = 무채색 슬레이트
- 주요 동작(Primary) = 파랑 `#1D4ED8` — 4색 등급 램프 밖의 색이라 충돌하지 않는다
- 파괴적 동작(차단·정지·삭제)만 예외적으로 적색 계열을 쓰되, **등급 배지와 같은 화면에 놓일 때는 채움 대신 외곽선**으로 낮춘다

## 2. 등급 토큰 (고정)

| 등급 | Final Score | 표시값 | 라이트 전경 | 라이트 배경 | 다크 전경 | 도형 |
|---|---|---|---|---|---|---|
| 정상 | 0.0–0.3 | 0–29 | `#15803D` | `#F0FDF4` | `#4ADE80` | ● 원 |
| 주의 | 0.3–0.6 | 30–59 | `#A16207` | `#FEFCE8` | `#FACC15` | ◆ 마름모 |
| 경고 | 0.6–0.8 | 60–79 | `#C2410C` | `#FFF7ED` | `#FB923C` | ▲ 삼각형 |
| 위험 | 0.8–1.0 | 80–100 | `#B91C1C` | `#FEF2F2` | `#F87171` | ■ 사각형 |

전경색은 전부 각 배경 위 4.5:1 이상이다.

**도형이 장식이 아니다.** `주의`(#A16207)와 `경고`(#C2410C)는 인접 색상이라 색만으로는 구분이 어렵고, 적록색각 이상에서는 `정상`과 `위험`이 붙는다. UX 규칙 `색만으로 정보를 전달하지 않는다`에 따라 **등급은 언제나 색 + 도형 + 한글 라벨 + 숫자 네 겹으로 표시한다.** 넷 중 하나라도 빠지면 안 된다.

계약서 §"이상점수와 상태 등급": 등급은 언제나 위 표로 **계산**한다. 데이터에 적힌 등급 라벨을 그대로 쓰지 않는다.

> **경계값 미정** — 계약서는 구간을 `0.0–0.3`, `0.3–0.6`처럼 적어 경계값(정확히 0.3)이 어느 등급인지 정하지 않았다. `frontend/dashboard/RealtimeDashboard.jsx:15`는 `s <= g.max`로 하위 등급(0.3 → 정상)을 택했다. 목업은 이 규칙을 따르되, 확정 전까지 경계값 데이터를 쓰지 않는다.

## 3. 색 토큰

라이트가 기본이다. 계약서 F14가 테마 3종(라이트·다크·시스템) 선택을 고정 요구하므로 **모든 색은 의미 토큰으로만 참조하고 원시 hex를 컴포넌트에 직접 쓰지 않는다.**

| 역할 | 토큰 | 라이트 | 다크 |
|---|---|---|---|
| 배경 | `--bg` | `#F8FAFC` | `#0F172A` |
| 표면 | `--surface` | `#FFFFFF` | `#1B2336` |
| 표면(한 단계 낮음) | `--surface-sunken` | `#F1F5F9` | `#161E2F` |
| 본문 | `--fg` | `#0F172A` | `#F8FAFC` |
| 보조 텍스트 | `--fg-muted` | `#475569` | `#94A3B8` |
| 테두리 | `--border` | `#E2E8F0` | `#334155` |
| 테두리(강조) | `--border-strong` | `#CBD5E1` | `#475569` |
| 주요 동작 | `--primary` | `#1D4ED8` | `#60A5FA` |
| 주요 동작 위 글자 | `--on-primary` | `#FFFFFF` | `#0F172A` |

`--fg-muted`(`#475569`)는 흰 배경 위 7.5:1이다. 계약서가 요구하는 정보(마지막 수신 시각, 진단기 상태 등)를 보조 텍스트로 내려도 읽힌다.

## 4. 타이포그래피

**본문 `Pretendard`(한글) · 수치 `JetBrains Mono`.**

- 화면 문구가 전부 한국어이고 한/영 토글이 있으므로(계약서 T9-5) 한글 자족이 필수다. Fira Sans는 한글이 없다.
- **모든 측정값·점수·시각·ID는 등폭(`JetBrains Mono`) + `font-variant-numeric: tabular-nums`.** F4 제약 "실시간 갱신 중 요소의 위치와 크기가 흔들리지 않아야 한다"를 지키는 수단이다. 비례 숫자를 쓰면 `12.7 A` → `18.9 A`에서 폭이 바뀌어 흔들린다.

| 토큰 | 크기 / 행간 | 용도 |
|---|---|---|
| `--text-score` | 44px / 1.0 | 이상점수 대표 숫자 |
| `--text-metric` | 24px / 1.1 | V·I·T·SOC 현재값 |
| `--text-h1` | 20px / 1.3 | 화면 제목 |
| `--text-h2` | 15px / 1.4 | 구획 제목 |
| `--text-body` | 14px / 1.5 | 본문 |
| `--text-sm` | 13px / 1.45 | 표 셀, 보조 |
| `--text-xs` | 11px / 1.4 | 라벨, 배지 |

본문 최소 13px. 11px는 라벨·배지에만 쓰고 문장에는 쓰지 않는다.

## 6. 터치 · 반응형

계약서는 반응형 3종(데스크톱·태블릿·모바일)을 **고정** 요구사항으로 둔다.

| 폭 | 레이아웃 |
|---|---|
| ~767px | 단일 컬럼, 하단 내비 5개 이하, 표 → 카드 목록 전환 |
| 768~1023px | 2컬럼, 사이드바 접힘 |
| 1024px~ | 사이드바 고정 + 다중 컬럼 |

- 터치 대상 최소 44×44px, 간격 8px 이상
- 표는 모바일에서 가로 스크롤이 아니라 카드로 바꾼다. 단 `--space` 조밀도 때문에 카드에서도 값은 등폭 유지
- 모바일 우선 노출: 현재 이상점수 · 등급 · 릴레이 차단 진입 · 미확인 알림 (CLAUDE.md 웹 디자인 원칙)

## 7. 모션 (Motion 3/10)

- 전환 150–250ms, `ease-out`. 라우트 전환은 opacity만 200ms
- **실시간 값은 애니메이션하지 않는다.** 숫자 카운트업·차트 트윈은 F4의 흔들림 금지 제약과 충돌한다. 값은 즉시 교체하고, 갱신 사실은 별도의 미세한 신호(수신 표시등)로 알린다
- 위험 등급의 맥동(pulse)은 허용하되 `prefers-reduced-motion: reduce`에서 반드시 멈춘다. 멈춘 상태에서도 등급은 도형+라벨+숫자로 읽혀야 한다
- 스트리밍 차트에는 일시정지 수단을 둔다 (chart DB: Real-Time Streaming 접근성 등급 B의 필수 보완)

## 8. 차트

| 용도 | 차트 | 근거 |
|---|---|---|
| 이상점수 추세 + 이상 이벤트 (F4·F7·F8) | 하이라이트 있는 선 차트 | 이상 지점을 **색이 아닌 도형 마커**로 찍고 텍스트 주석을 단다 |
| V·I·T·SOC 4지표 동시 (F9) | 소형 다중 선 차트 4개 | F9는 지표 선택 수단이 없다 — 항상 4개 동시 표시 |
| 이상점수 대표값 (F4) | 게이지 + 4구간 눈금 | 4구간을 **모두** 표시. 3구간은 v3 버그 |
| 위험도 분포 (F8) | 4칸 고정 막대 | 0건 구간도 반드시 자리를 차지한다 |
| 이벤트 추이 (F20) | 등급별 누적 막대 | 주의·경고·위험 3등급만 집계 (정상 제외) |

- **데이터 없는 구간과 값 0을 반드시 다르게 그린다** (F9 제약). 없는 구간은 선을 끊고 배경에 빗금을 깐다. 0으로 이어 그리면 안 된다
- 축 라벨은 서버 문자열이 아니라 절대 시각에서 화면이 계산한다 (F20 제약)

## 9. 이 제품에서 금지

계약서 §"하지 말 것"에서 화면에 직접 걸리는 것들:

- ❌ 등급 범례를 3구간(정상 0~39 / 주의 40~69 / 위험 70+)으로 그리기 — v3 버그
- ❌ 이상점수를 등급 없이 단독 표시 (F4 제약)
- ❌ 셀 단위 데이터 — 히트맵, 셀별 온도, 이벤트명의 `· 셀 N` (F7·F10 제약)
- ❌ 재인증·사유 입력을 건너뛰는 차단·복구 경로 (T7 불변)
- ❌ 배터리 미연결 상태에서 잠긴 8개 목적지를 열어주기 (T0 불변)
- ❌ 상대 시간("2일 전")을 서버 문자열로 받아 그대로 출력 — 절대 시각에서 화면이 계산 (F4 제약)
- ❌ 부록 A에 없는 수치 지어내기

일반 UI 금지:

- ❌ 이모지를 아이콘으로 사용 → SVG (Lucide)
- ❌ 포커스 링 제거
- ❌ 색만으로 정보 전달
- ❌ 즉시 상태 변경(0ms 전환)
- ❌ 레이아웃을 밀어내는 hover 변형 — 조밀한 표에서 특히 금물

## 10. 납품 전 점검

- [ ] 4등급이 색+도형+라벨+숫자 네 겹으로 표시되는가
- [ ] 등급이 데이터 라벨이 아니라 임계값에서 계산되는가
- [ ] 등급 범례가 4구간인가
- [ ] 크롬(배경·테두리·기본 버튼)에 녹/황/주황/적이 없는가
- [ ] 모든 측정값이 `tabular-nums` 등폭인가 (갱신 시 흔들리지 않는가)
- [ ] T0 잠금 상태에서 배터리 자산관리만 열려 있는가
- [ ] 잠긴 목적지가 "잠겼다는 사실 + 푸는 방법"을 보여주는가
