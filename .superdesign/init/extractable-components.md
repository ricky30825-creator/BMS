# Extractable components

No framework component extraction is required before concept design because the source is a standalone HTML mockup with no import graph.

Reusable layout-level elements visible in F4:

1. Application shell: sidebar, top header, main content, mobile bottom navigation
2. Connected battery session bar
3. Anomaly score panel: four-band gauge, score, grade, legend, evidence and trend actions
4. Four-metric current-value group
5. Metric selector plus deterministic live trend chart
6. Recent notice list and all-notices action
7. Relay cut entry action
8. Locked-state panel for no connected battery

These should remain recognizable functional units across six concept branches, but their composition and hierarchy may differ.
