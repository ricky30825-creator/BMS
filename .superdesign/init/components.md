# Shared UI primitives

The current product mockup is a standalone HTML application. It has no imported component files; all primitives live in `web/cellguard_mockup_v4.html`.

## Actual primitive source map

- Buttons: `.btn`, `.btn-primary`, `.btn-ghost`, `.btn-danger`, `.btn-sm`
- Surfaces: `.card`, `.card-head`, `.notice`, `.empty`, `.locked`
- Status: `.badge`, `.legend`, `.legend-row`, `badge(score)`, `gauge(score)`, `gradeOf(score)`
- Live values: `.metric`, `.metrics`, `.num`, `.gauge`, `.readout`
- Navigation: `.nav-item`, `.bottomnav`, `.sheet-item`, `renderNav()`
- Controls: `.seg`, `.toggle`, modal overlay and action rows
- Charts: `sparkline(metricKey)`, `trendChart(m, batteryIds)`
- Icons: inline SVG generated by `icon(name, className)`; no emoji icons

## Primitive contract

All numeric values, times, and IDs use JetBrains Mono with tabular numerals. Status is never color-only: every grade combines a shape, Korean label, number, and semantic color. Live values replace in place without count-up animation or layout movement. Destructive relay actions are outline-style and route to the reason plus re-authentication flow rather than mutating state optimistically.

## Full source authority

Because the application is monolithic, the complete source of every primitive is the single file `web/cellguard_mockup_v4.html`. For F4 design work, the relevant rendered primitive definitions are CSS lines 1-300, application shell lines 430-550, data and grade helpers lines 552-791, and F4 rendering lines 792-909.
