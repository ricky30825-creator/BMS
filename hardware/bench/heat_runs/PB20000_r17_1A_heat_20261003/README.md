## 해석할 때 주의

- **6채널 학습에 쓰지 말 것.** 이 run 에는 접촉 온도 프로브가 없다. 열 이름 `ds_far_c` 는 **실온 프로브**(DS18B20) 값이고
  `ds_near_c` 는 결측이다 (근처 프로브 `28-0625657fe542` 가 VCC 불량으로 85.0℃ 고정이었다).
- `heat_off` 3개는 **추정 시각**이다 (1번 = tempguard 차단 시각, 2번 = INA 접촉이 끊긴 시각, 3번 = IR 최고점 직후).
- 가열 1번은 `tempguard` 급상승 규칙(40℃ 이상에서 60초 10℃)이 방전을 끊었다. 2번은 INA 배선을 건드려 방전이 끊겼다.
  전기 비교는 `current_a < -0.5` 인 샘플만 쓴다.
- 실온 프로브가 열풍 경로에 있어 가열 중 같이 올라갔다 (구간 2에서 실온이 표면을 앞섰다).
  **한 프로브로는 환경 열과 자체 발열을 못 가른다**는 관찰이며, 한 run 의 결과다. 근처/먼 프로브 비교는 아직 못 했다.
- BW150 화면 교차검증: 시간 44:23 / 738 mAh / 3.447 Wh. INA 적분은 44:16 / 729.7 mAh / 3.657 Wh.
  에너지 −5.7% 차이는 측정 위치(INA 는 팩 쪽, BW150 은 부하 단자) 차이로 본다.
- 개발 단계 값이며 hold-out 검정이 없다.
