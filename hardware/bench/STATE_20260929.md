## 6. 가열(환경 열 스트레스) 실험 계획

목적: 이상 샘플 중 **열 이상이 하나도 없다**. 그리고 발열값(표면−실온)이 「환경 탓」과 「자체 발열」을 가르는지 검증.

- DS18B20 둘을 동시에: **근처 프로브**(배터리 옆 공중, 닿지 않게, MLX 시야 밖) + **먼 프로브**(10cm 이상, 바람 밖).
- `edge/heat_run.sh` 가 점검·로거·`mark heat_on/off`·자동 종료를 묶는다. **`probes`·`start`·`go` 는 아직 실기 검증 전.**
- 이 run 의 `ds18b20_c` 는 접촉 온도가 아니라 근처 공기다 → 6채널 학습에 쓰지 말 것(접두 `_heat`).
- **안전**: 표면 45℃ 상한, PB-5000·1A, 열화 팩 금지, 자리를 비우지 않는다, 불연 표면. `tempguard` 는 부하 릴레이만 열고 **열원은 못 끈다**.
  열폭주 근처까지 가는 실험은 하지 않는다. 멘토에게 안전 절차를 확인받고 진행.
