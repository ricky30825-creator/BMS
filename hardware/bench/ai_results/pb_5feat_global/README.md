## r17 가열 run 을 hold-out 으로 채점 (학습에 전혀 안 씀)
`PB20000_r17_heat_scores_global.csv`, 채점은 `tools/score_heat.py`.

- **최종 점수는 가열 전(pre)도 75%가 이상으로 나온다** → 가열을 잡았다고 말할 수 없다.
- 이유(채널별 z, 중앙값): pre 에서 `voltage_v` 37~65, `power_discharge_w` 53~85, **IR 두 채널 0.1~0.2**. 이 run 의 전압 거동(1A 에서 4.86~5.04 V 로 ±2% 출렁임)이 학습 분포 밖이다.
- 가열 구간에서는 IR 채널이 크게 뛴다: 가열1 `ir_b` 135~485, 가열3 `ir_a` 34~61 / `ir_b` 89~208. **IR 채널 자체는 열에 반응하고 pre 와 분리된다.**
- 즉 모델의 열 감지 신호는 있으나, 전압·전력 채널의 분포 이탈이 최종 점수를 지배한다. 원인 확인 전에 임계/융합을 바꾸지 않는다.
- r17 은 PB-20000 1A(계획의 PB-10000 2A 가 아님), 환경 열(드라이어)이며 배터리 자체 이상이 아니다. run 1개.
