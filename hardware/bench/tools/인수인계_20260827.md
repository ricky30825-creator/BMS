## 1. 즉시 이어서 할 것 — 릴레이 진단

### 증상

| 관찰 | 값 |
|---|---|
| LED | **네 채널 모두 켜진다** → 제어 신호는 정상 도달 |
| 딸깍 | **CH1(gpio5)만 난다.** CH2·CH3·CH4 무음 |
| `VCC` ↔ `GND` (무부하) | 3.2 V (정상) |
| `JD-VCC` ↔ `GND` (무부하) | 5.0 V (정상) |
| CH3 `COM`↔`NO` | 코일 ON에서도 안 닫힘 |
| 부하 전류 | 0 A (마스터 접점이 안 닫히니 당연) |

LED는 `VCC`(3.3V)로 켜지고 **코일은 `JD-VCC`(5V)로 당긴다.**
LED만 켜지고 딸깍이 없다 = **코일 전원 계통 문제**로 좁혀진다.

### 다음에 잴 것 — 두 개면 확정된다

**① `JD-VCC`를 코일 통전 중에 재라** ← 아직 안 쟀다

무부하 5V는 전류가 0일 때 값이라 아무것도 증명 못 한다. 코일이 당길 때 70~80 mA가
필요한데, 접촉이 헐거우면 그 순간 전압이 무너진다.

```bash
ssh <USER>@<IP> 'pinctrl set 5,6,19 op dh; sleep 0.5; pinctrl set 13 op dl'
```

이 상태에서 `JD-VCC ↔ GND` 측정:

| 결과 | 진단 | 조치 |
|---|---|---|
| **3~4 V로 주저앉음** | 코일 전원이 전류를 못 준다 | `JD-VCC` 점퍼 재결선·굵은 선 |
| **5 V 유지** | 전원 충분 → 릴레이 3개 물리 고장 | 보드 교체 |

**② 3핀 블록(`JD-VCC`/`VCC`/`GND`)의 점퍼 캡 유무**

| 상태 | 의미 |
|---|---|
| 캡이 `JD-VCC`–`VCC`를 이음 | 코일이 3.3V로 동작 → 5V 릴레이엔 부족. **하나만 겨우 당겨지는 것과 맞는다** |
| 캡 없고 `JD-VCC`에 5V 별도 공급 | 정상 구성 |

## 3. 연기 사고 (2026-08-27 저녁)

### 경과

```
BW150 팬 제거(케이스 면적 확보) → 100℃ Run Stop 걸림 → 팬 재조립
   ↓  그 과정에서 센서 이탈 반복 (DS 6490 / MLX 5B / INA226 ×2)
"배선 문제 없어 보임" → 다시 부하 인가
   ↓
연기 → 즉시 전원 전부 차단
```

### 확인된 결함

- **BW150 `A−` 나사 단자에서 선이 빠져 있었다**
- 단자 뒤 납땜부에 **맨 심선이 여러 곳 노출**

`A−`가 빠진 채 2선식 점퍼(`A−`↔`V−`)가 있으면 **부하 전류가 얇은 감지선으로 흐른다.**
또는 빠진 맨 심선이 다른 도체에 닿았다. 둘 다 **부품 손상 없이 연기만 나는** 경로다.

> ⚠️ `SOURCE_P` 구간은 CH3 앞이라 **퓨즈가 없다.** 가이드가
> *"노출 심선을 남기지 않는다"*고 못박은 이유가 이것이다.

### 반드시 할 것

1. **모든 노출 접합부 절연** — 수축튜브. 예외 없이
2. **`A−`는 0.75SQ**로, 넣고 **당겨서 안 빠지는지 확인**
3. **다발 고정** — 케이블 타이. 오늘 배선 이탈이 **일곱 번**이었다
4. `V−`에 물려 있던 얇은 선은 **변색·수축이 있으면 잘라내고 교체**

```
① 모든 듀폰 점퍼 뽑았다 다시 꽂기 (늘어난 클립이 근본 원인)
② 전 커넥터 고정 (케이블 타이·글루건)
③ preflight <접두>          → 6채널 OK
④ i2cstress.py 30           → 실패 0 확인
⑤ 릴레이 4채널 딸깍 + LED 1:1 대응
⑥ 팩 뽑은 채 CH3 COM↔NO 도통
      코일 OFF → 열림 / 코일 ON → 삑     ← 이걸 건너뛰지 말 것
⑦ 그 다음에야 통전 (파이만 → BW150 → 배터리 → 1A)
```

### run 시작 순서 (팩 잠듦 방지)

```
① BW150 CP/CC 값 설정 + Cap/Ene 0 초기화
② BW150 출력 ON          ← 먼저
③ 팩 버튼 눌러 깨우기
④ 그 다음 CH3 ON
```

보조배터리는 **무부하 30~40초면 스스로 잠든다.** 오늘 다섯 번 당했다.
